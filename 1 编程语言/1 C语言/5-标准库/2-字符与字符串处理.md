## 一、string.h

对于接受字符串作为参数的函数来说，这个函数可能会对参数的内容进行修改，在这种情况下，只能传入指向字符数组首元素的指针。

- `size_t strlen(char const *string);`：字符串长度

  - 参数：字符串
  - 返回值：传入字符串的`char`个数，**以`'\0'`为止，不包括`'\0'`**。

- `char *strcpy(char *dst, char const *src);`：复制字符串

  - 参数：`dst`为目标字符串（**必须为字符数组，且空间应该大于或等于`strlen(src) + 1`**），`src`是被复制的字符串
  - 返回值：返回`dst`的值

- `char *strcat(char *dst, char const *src);`：将`src`字符串连接在`dst`之后

  - 参数：`dst`为目标字符串（**必须是字符数组，且空间应该大于或等于`strlen(dst) + strlen(src) + 1`，要求`dst`必须原来保存了一个完整的字符串，包括空串，即必须有`'\0'`字符**）
  - 返回值：返回`dst`的值

- `int strcmp(char const *s1, char const *s2);`：比较两个字符串

  - 参数：`s1`和`s2`为两个待比较的字符串
  - 行为：从头对两个字符串的每个字符依次进行比较，遇到两个不相同的字符串时返回两字符串不同的结果，若直到两字符串都比较完末尾的空字符后仍未找到不同字符，则两字符串相同
    - 当遇到不同时，其中一个字符串中的字符小于或大于另一个字符串中对应位置的字符，则认为前者字符串小于或大于后者
    - 若直到某一方遇到`'\0'`，另一方还未遇到`'\0'`，但后者的前半段都与前者完全相同，此时更长的字符串更大。因为`'\0'`是最小的字符，若另一个字符串未结束，那么无论在这个相同位置的字符是什么，都会比`'\0'`大
  - 返回值：当两字符串相同则返回 0，若`s1 < s2`（此处含义与程序内的相同表达式含义不同），则返回一个负数，若`s1 > s2`，则返回一个正数

- `char *strncpy(char *dst, char const *src, size_t len);`：限定长度的字符串拷贝

  - 参数：`dst`、`src`的含义和`strcpy`函数相同，`len`表示需要拷贝的字符数量。**程序员需要保证`dst`的空间大于或等于`len`。**
  - 行为：将`src`中的字符依次拷贝给`dst`。若`strlen(src) < len`，那么将用额外的`'\0'`字符填充到`len`长度；若`strlen(src) >= len`，那么将只复制`len`个字符到`dst`中，且该结果将不会以`'\0'`字符结尾。**故程序员还通常需要保证`strlen(src) < len`**
  - 返回值：仍然返回`dst`的值

- `char *strncat(char *dst, char const *src, size_t len);`：限定长度的字符串连接

  - 参数：`dst`、`src`的含义和`strcat`函数相同，`len`表示从`src`中选取的字符个数。**程序员需要保证`dst`的空间大于或等于`strlen(dst) + len + 1`**
  - 行为：`src`中的字符从头开始依次拷贝到`dst`中，从`dst`中第一个`'\0'`开始覆盖，包括这个`'\0'`，最多拷贝`len`个字符，若`strlen(src) < len`，多出来的部分也不会用`'\0'`填充，拷贝完成后在`dst`末尾加上一个`'\0'`
  - 返回值：仍然返回`dst`的值

- `int *strncmp(char const *s1, char const *s2, size_t len);`：限定长度的字符串比较

  - 参数：`s1`、`s2`的含义和`strcmp`函数相同，`len`表示最多需要比较的字符数量。
  - 行为：若两个字符串的前`len`个相同位置上的字符存在不相等情况，则这个函数停止比较并返回结果；若两个字符串的前`len`个字符相等，函数就返回 0
  - 返回值：和`strcmp`含义相同

- `char *strchr(char const *str, int ch);`：查找字符串`str`中第一次出现`ch`的位置

  - 参数：`str`为待查找字符串；`ch`是待查找字符
  - 返回值：指向`str`中第一个`ch`字符的指针，若无则为`NULL`

- `char *strrchr(char const *str, int ch);`：查找字符串`str`中最后一次出现`ch`的位置

  - 参数：`str`为待查找字符串；`ch`是待查找字符
  - 返回值：指向`str`中最后一个`ch`字符的指针，若无则为`NULL`

- `char *strpbrk(char const *str, char const *group);`：查找字符串`str`中第一次出现`group`中任意一个字符时的位置

  - 参数：`str`为待查找字符串；`group`字符串中除`'\0'`之外的每一个字符都是待查找字符
  - 返回值：指向`str`中第一个`group`中任意字符的指针，若无则为`NULL`

- `char *strstr(char const *s1, char const *s2);`：在`s1`中查找子串`s2`

  - 参数：`s1`为主串，`s2`为待查找的子串
  - 返回值：指向`s1`中第一次出现`s2`的起始位置；若`s2`是一个空串，则返回`s1`；否则返回`NULL`

- `size_t strspn(char const *str, char const *group);`：在字符串起始位置对匹配字符计数

  - 参数：`str`为主字符串，`group`用于指定除`'\0'`之外的每一个待计数字符
  - 行为：从`str`第一个字符开始，若该字符在`group`中存在，则返回值加 1；若不存在，则结束函数并返回计数值
  - 返回值：`str`中起始位置与`group`中任意字符匹配的字符个数

- `size_t strcspn(char const *str, char const *group);`：在字符串起始位置对不匹配字符计数

  - 参数：`str`为主字符串，`group`用于指定除`'\0'`之外的每一个待排除字符
  - 行为：从`str`第一个字符开始，若该字符在`group`中不存在，则返回值加 1；若存在，则结束函数并返回计数值
  - 返回值：`str`中起始位置与`group`中每个字符都不匹配的字符个数

- `char *strtok(char *str, char const *sep);`：查找标记

  - 参数：`str`为待查找字符串（**要求必须是数组**）或者为`NULL`；`sep`为用作分隔符的字符集合
  - 行为：
    - 当`str`不为`NULL`时，函数将找到字符串的第 1 个标记，函数将返回它在字符串中的位置，同时将这个标记末尾的分隔符修改为`'\0'`，然后**保存**这个`'\0'`字符后的位置，**`strtok`函数的调用循环应该从这一步开始**；
    - 当`str`为`NULL`时，函数就在同一个字符串中从这个被保存的位置开始像前面一样查找下一个标记，并按照上面的行为一样将查找到的标记末尾的分隔符修改为`'\0'`，并返回这个标记的起始位置，同时保存这个`'\0'`字符后的位置；
    - 如果函数不存在更多的标记，函数将返回一个`NULL`指针，**此时这个调用循环结束**
  - 返回值：若找到标记则返回该标记的起始位置的指针，否则返回`NULL`

  > `strtok`能实现上述循环调用的行为是因为它保存它所处理的函数的局部状态信息，因此不能用它同时解析两个字符串

- `char *strerror(int error_number);`：获取错误信息

  - 参数：`error_number`用于转换为错误信息的错误代码，可用一个外部整型变量`errno`作为实参，其保存了最近一次错误的错误代码
  - 返回值：指向用于描述错误的字符串的指针。不应该修改返回值



## 二、ctype.h

- 字符分类

  以下函数接受一个包含字符值的整型参数，函数测试这个字符并返回一个整型值 1 或 0，

  | 函数       | 为真的情况                                              |
  | ---------- | ------------------------------------------------------- |
  | `iscntrl`  | 任何控制字符                                            |
  | `isspace`  | 空白字符：`' '`、`'\f'`、`'\n'`、`'\r'`、`'\t'`、`'\v'` |
  | `isdigit`  | 十进制数字                                              |
  | `isxdigit` | 十六进制数字                                            |
  | `islower`  | 小写字母                                                |
  | `isupper`  | 大写字母                                                |
  | `isalpha`  | 字母                                                    |
  | `isalnum`  | 字母或数字                                              |
  | `ispunct`  | 标点符号，任何不属于字母或数字的图形字符                |
  | `isgraph`  | 任何图形字符                                            |
  | `isprint`  | 任何可打印字符，包括图形字符和空白字符                  |

- 字符转换

  - `int tolower(int ch);`：返回`ch`的小写形式，参数本身的值不改变
  - `int toupper(int ch);`：返回`ch`的大写形式，参数本身的值不改变



## 三、内存操作

下面一组操作与对应的字符串操作函数类似，但它们使用范围更广，适合多种类型的数组，称为内存操作函数：

- `void *memcpy(void *dst, void const *src, size_t length);`：内存拷贝，将`src`中`length`个**字节**拷贝到`dst`中，返回`dst`
- `void *memmove(void *dst, void const *src, size_t length);`：内存移动，和`memcpy`类型，但允许`dst`和`src`重叠，通常用于将数组元素整体向前或向后移动`length`个**字节**，返回`dst`。移动时不用担心对数组的改变会影响到最终结果，因为该函数会创建临时数组
- `void *memcmp(void *a, void const *b, size_t length);`：内存比较，但按照**无符号字符逐字节**进行比较
- `void *memchr(void const *a, int ch, size_t length);`：查找`ch`字符第一次出现的位置，只查找`length`个**字节**
- `void *memset(void *a, int ch, size_t length);`：将从`a`开始的`length`个**字节**都设置为字符值`ch`

**注意**：内存操作都是对字节进行操作，如果传入的是多字节的类型，`length`则需要乘以一个`sizeof(Elem_type)`
