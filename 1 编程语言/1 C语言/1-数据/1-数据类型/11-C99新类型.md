## 一、`_Bool`类型

`_Bool`类型是 C99 新增的内置类型而非宏定义，它的值只会是 0 或 1，用于表示假或真，C99并没有为这个新类型设置特殊的字面值。

它的底层实现可能是 1 位、可能是 1 字节，这取决于实现。但它的值只会是 0 或 1，这句话的意思是即使用非 0 非 1 的其他整数赋值给`_Bool`类型的变量，也会被转换为 1。

可以包含`stdbool.h`的头文件，该头文件中将`_Bool`定义为了`bool`，并且将`1`和`0`分别定义为了`true`和`false`，可以更方便地使用。



## 二、复数与虚数类型

- 三种复数类型：`float _Complex`、`double _Complex`、`long double _Complex`
- 三种虚数类型：`float _Imaginary`、`double _Imaginary`、`long double _Imaginary`（实现可选不支持虚数类型）

复数类型由实部和虚部构成，实部和虚部的数据类型就是`_Complex`之前的类型，要使用复数类型，需要和`complex.h`头文件一起使用，如果不用`complex.h`头文件，那么一个复数变量只能初始化其实部数据，即：

```c
double _Complex z = 1.0;
```

这个`1.0`只会用来初始化`z`的实部数据。

****

如果包含`complex.h`头文件，那么`_Complex`可以使用`complex`替代，初始化一个复数数据可以使用：

```c
double complex  z = 1.0 + 2.0 * I;
```

其中`I`是`complex.h`中的一个宏，这样的写法可以表示`2.0`为虚部数据。

另外，如果要分别获取一个复数变量的实部和虚部数据需要使用头文件中的函数：`creal(z)`、`cimag(z)`，它们默认是处理`double complex`类型的，处理`float`类型的对应函数是：`crealf(z)`、`cimagf(z)`；以及处理`long double`类型的对应函数：`creall(z)`、`cimagl(z)`

头文件中还有很多函数可以用于进行复数的相关计算

****

而虚数类型和复数类似，它的相关宏以及函数也定义在`complex.h`头文件中，不再过多介绍
