## 一、整数类型

### 1. 类型

| 类型                             | 尺寸       |
| -------------------------------- | ---------- |
| `short`                          | 至少 16 位 |
| `unsigned short`                 | 至少 16 位 |
| `int`                            | 至少 16 位 |
| `unsigned`                       | 至少 16 位 |
| `long`                           | 至少 32 位 |
| `unsigned long`                  | 至少 32 位 |
| `long long`（C99 新增）          | 至少 64 位 |
| `unsigned long long`（C99 新增） | 至少 64 位 |

- 关键字：除`int`外，所有类型关键字后可以添加`int`关键字；所有有符号类型可以在类型前添加`signed`关键字强调该类型为有符号类型



### 2. 数据

- 通常采用补码实现，但 C 语言并未规定，则可能采用原码或反码实现
- `1 == sizeof(char) ≤ sizeof(short) ≤ sizeof(int) ≤ sizeof(long) ≤ sizeof(long long)`



## 二、字面值

- 十进制、八进制（前缀`0`）或十六进制（前缀`0x`或`0X`）的整数字面值。
- 同时，字面值还有`u/U`（`unsigned`）、`l/L`（`long`）、`ll/LL`（`long long`）这几个后缀，其中`l/L`后缀不能和`ll/LL`后缀同时出现。

整数字面值的类型由后缀和进制共同决定，通常是一个候选类型列表中能保存该字面值的最小类型，候选列表如下表：

| 后缀           | 十进制底                                                  | 其他底                                                       |
| -------------- | --------------------------------------------------------- | ------------------------------------------------------------ |
| (无后缀)       | `int`<br />`long`<br />`long long`                        | `int`<br />`unsigned`<br />`long`<br />`unsigned long`<br />`long long`<br />`unsigned long long` |
| `u/U`          | `unsigned`<br />`unsigned long`<br />`unsigned long long` | `unsigned`<br />`unsigned long`<br />`unsigned long long`    |
| `l/L`          | `long`<br />`long long`                                   | `long`<br />`unsigned long`<br />`long long`<br />`unsigned long long` |
| `l/L`和`u/U`   | `unsigned long`<br />`unsigned long long`                 | `unsigned long`<br />`unsigned long long`                    |
| `ll/LL`        | `long long`                                               | `long long`<br />`unsigned long long`                        |
| `ll/LL`和`u/U` | `unsigned long long`                                      | `unsigned long long`                                         |



## 三、类型转换与允许值

### 1. 整型值

- 小整型 —— 大整型：隐式类型提升。无数据损失
- 大整型 —— 小整型：允许隐式转换。截断

> 此处的整型包括字符类型



### 2. 浮点值

- 浮点值 —— 整型值：允许隐式转换。小数部分截断，仅保留整数部分

  > C99 之前对于负数的截断根据实现而定，可能按照向左取整的原则进行截断。
  >
  > 从 C99 开始，截断原则规定为趋零截断，即直接丢弃小数部分，整数部分不变。



### 3. 指针值

- 指针 —— 整型值：不允许隐式转换（但部分编译器默认可能只给出警告）。需要用足够大的整型保存，例如 64 位程序就需要用 64 位的整型保存指针，否则会被截断。如果用于保存指针的整型尺寸不足，编译器可能会反馈一个错误，也可能仅反馈一个警告。

> 此处的指针包括数组名，数组名会先隐式转换为指针
