## 一、运算符

### 1. 算术运算符

```c
+ - * / %
```

- `%`：取模运算符，仅能作用于两个整数
- 其他运算符：当两个操作数都是整数时为整数运算，否则为浮点运算



### 2. 移位操作符

```c
<< >>
```

- 移位操作两边的操作数都要是整数，移位数量应该控制在 0 到左侧整型位数之间，否则行为未定义
- 左移：抛弃左边移出范围的位，右侧多出的位用 0 填充
- 右移：抛弃右边移出范围的位，如果是无符号整型，那么左边多出的位用 0 填充（即逻辑移位）；如果是有符号整型，那么左边多出的位可能用 0 也可能用符号为进行填充，取决于编译器。

> 移位操作符不会对左侧运算对象做出修改，仅计算得出结果



### 3. 位操作符

```
& | ^ ~
```

- 只接受两个整数类型，`~`只接受一个整数类型
- 当两个整数类型不同时，小的提升为大的类型



### 4. sizeof

```c
sizeof(expression);
sizeof variable;
```

- `sizeof`的操作数可以是表达式（包括单个变量），也可以是类型名
- 当`sizeof`的操作数只有一个变量时，可以不添加括号，否则需要添加括号（包括类型名），变量也可以添加括号
- `sizeof`的操作数如果是一个表达式，则该表达式不会执行



### 5. 递增递减

```c
++ --
```

- 前置版本：左值递增/递减，表达式值为递增/递减后的值
- 后置版本：左值递增/递减，表达式值为递增/递减前的值



### 6. 关系运算符

```c
> >= < <= != ==
```

- 运算结果是整型值而非布尔值，但只会返回 0 或者 1



### 7. 逻辑操作符

```c
&& || !
```

- 能作为`if`、`while`等语句的`expression`部分的表达式都可以作为逻辑操作符的操作数
- `&&`、`||`采取短路求值的方式。对于`&&`，若左操作数为假，则不再计算右操作数；对于`||`，若左操作数为真，则不再计算右操作数



### 8. 条件操作符

```c
expression1 ? expression2 : expression3
```

- 根据`expression1`的结果，若为真，则`expression2`求值，`expression3`不求值；若为假，则反之



### 9. 逗号操作符

```c
,
```

- 从左至右依次计算操作数的值，返回右测操作数的值



## 二、左值和右值

在 C 语言中，能在赋值符左边的就是**左值**，能在赋值符右边的就是**右值**。左值通常也能作为右值使用，而右值通常不能作为左值使用。

部分运算符要求操作数是一个左值，例如赋值运算符、递增递减运算符。

> 部分运算符和 C++ 中的定义不同，例如前置递增递减运算符，在 C 语言中该运算符返回的结果是右值而非左值，故不能放在赋值符的左侧，而 C++ 中该运算符返回的结果是左值



## 三、表达式求值

### 1. 隐式转换

#### 整型提升

整型算术运算总是以缺省整型类型的精度来进行的。

`char`和`short`在表达式里或作为函数的实参时，都会被提升为`int`类型；

`float`作为函数的实参时也会被提升为`double`类型。

#### 算术转换

整型提升之后，进行算术转换。如果某个操作符的各个操作数属于不同的类型，则会进行算术转换，下面的层次体系称为**寻常算术转换**：

```c
long double
double
float
unsigned long long
long long
unsigned long
long
unsigned
int
```

对于大部分运算符，都是由小类型转换为大类型，但对于赋值运算符，则是定向转换为左侧变量的类型，可能会有损失。

- 有损转换：整型向浮点数转换可能会有精度损失，例如整型值位数较多时；浮点向整数转换时会有损失
- 未定义转换：当浮点数的值过于庞大，无法容纳到整型值中时，该结果将是未定义的



### 2. 操作符的属性

复杂表达式的执行顺序由 3 个因素决定：操作符的优先级、结合性以及求值顺序

- 优先级、结合性影响的是哪个操作符先执行，并不决定哪一个操作数先计算
- 求值顺序决定操作数计算的先后顺序，但只有部分操作符会规定操作数的求值顺序

C 语言操作符的属性可参考：[C 运算符优先级](https://zh.cppreference.com/w/c/language/operator_precedence)
