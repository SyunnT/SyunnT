## 一、函数声明与定义

### 1. 函数定义

函数定义的形式如下：

```c
Ret_Type Func_Name(Arg_lists)
{
    statements;
}
```

- `Ret_Type`：返回类型，当无返回值时使用`void`
- `Arg_lists`：形参列表，当无参数时使用`void`



### 2. return 语句

`return`语句的用法有下面两种：

```c
return;
return expression;
```

`return`语句用来从函数中退出，可以出现在函数中任何位置。

- 对于`Ret_Type`为`void`的情况，只能使用第一种形式。禁止使用第二种形式（部分编译器只给出警告）
- 对于`Ret_Type`非`void`的情况，只能使用第二种形式（`expression`需要和`Ret_Type`类型匹配或能够隐式转换为该类型）。禁止使用第一种形式（部分编译器只给出警告）



### 3. 原型声明

代码中能够使用一个函数的前提是函数要先声明，而不要求函数先定义。

根据习惯，通常先将一个代码文件中会用到的所有函数先声明一遍函数原型，函数定义可以定义在别处。这样的好处是当这些需要用到的函数之间有交叉调用时，如果某个调用发生时该函数还未声明则会发生错误。

函数原型声明和函数定义的区别就是将函数体这个代码块换成一个分号：

```c
Ret_Type Func_Name(Arg_lists);
```

**注意**：

- C 语言中不允许函数重载，即同一作用域的两个同名函数表示的是同一个函数，所以它们的返回类型和形参列表顺序和类型都必须相同
- 原型声明中的形参可以没有名字，只有一个类型，因为原型声明并不会用到这些名字，有形参的类型就足够了



### 4. 无原型调用（C99 开始）

如果在调用之前没有声明函数原型或定义该函数，编译器会认为该函数返回一个`int`值，且形参随意。

当调用形参数量小于函数实际形参数量时，由于形参是自动存储期变量，所以未被初始化的形参会得到一个垃圾值；当调用形参数量大于函数实际形参数量时，多出来的形参会被丢弃。且编译器不会检测形参和实参的类型匹配，即便是非法类型转换也会通过编译。

调用时会将该函数的返回值当做`int`值处理，可以认为在调用时隐式的添加了一个原型声明，如果实际的函数定义返回类型不是`int`，那么就会出现原型和定义返回值类型不匹配的错误。

**以上使用方法均为危险操作，最好不要使用，许多编译器会将该用法识别为错误，但部分编译器仅给出警告**



## 二、参数

### 1. 传值调用

C 语言中所有的参数都是以值的方式进行传递的，即形参只是实参值的一个拷贝，对形参进行修改并不会影响到实参本身的值。

对于指针而言，由于它的值是另一个变量的地址，所以它本身通过传值调用将值传递给了形参，形参对指针本身的修改并不会影响到传入的指针所指向的地址。但由于它们都指向同一个地址，所以对形参进行间接访问并修改其所指内存中的内容会影响到传入的指针实参所指地址中的内容



### 2. 可变参数列表

可变参数列表需要用到一个类型`va_list`和 3 个宏`va_start`、`va_arg`、`va_end`。它们定义在`<stdarg.h>`这个头文件中。

- `va_list`：一种用来遍历省略符参数的变量类型，该类型的变量和上述 3 个宏结合使用可以依次得到省略符参数中每个参数的值
- `va_start`：一个类似于函数用法的宏。用于初始化一个`va_list`类型的变量
- `va_end`：用于结束一个`va_list`类型变量的生命周期
- `va_arg`：让一个`va_list`类型的变量指向下一个省略符形参中的参数

#### 省略符形参

一个接受可变参数列表的函数需要用省略符表示不确定的参数列表，省略符形参应该放在所有确定形参之后，且省略符形参之前应该至少有一个确定形参：

```c
float average(int n_values, ...);
```

**注意**：

- 上述的宏无法判断实际存在的参数的数量，所以通常需要传入一个指示数量的参数，可以像上述声明一样直接传入一个整数，也可以像`printf`函数那样，传入一个字符串，然后省略符形参中的数量可以根据字符串中格式代码的数量来判断
- 这些宏无法判断每个参数的类型，所以`va_arg`需要接受一个类型参数来计算偏移量

#### 使用 stdarg 库

- 创建`va_list`变量：

  ```c
  va_list va_var;
  ```

  此变量需要调用`va_start`宏函数进行初始化，不需要进行其他初始化

- 初始化`va_list`类型变量：

  ```c
  va_start(va_var, n_values);
  ```

  - 第一个参数：新建的`va_list`变量
  - 第二个参数：省略符形参前的最后一个确定形参，用于确定省略符形参第一个数据从何处开始，方便赋值给`va_var`

  > `va_list`变量必须通过`va_start`进行初始化后才能使用

- 获取下一个值并返回当前值：

  ```c
  va_arg(va_var, NextVal_Type);
  ```

  - 第一个参数：`va_list`类型变量

  - 第二个参数：省略符形参中当前值的类型，用于计算`va_var`到下一个数据的偏移量，同时`va_arg`调用的返回类型也将扩展为该类型

    > 由于省略符形参中没有类型限定，所以所有数据的类型将进行缺省类型提升，即`char`、`short`和`float`类型的值将提升为`int`或`double`类型的值传递给函数。
    >
    > 而`NextVal_Type`应该和提升后的实参类型相兼容，否则行为未定义，除非：
    >
    > - 一个类型是有符号整数类型，另一类型是对应的无符号整数类型，而且值可以被两类型一同表示；或
    > - 一个类型是指向 void 的指针，而另一个是指向字符类型的指针。

  - 行为：`va_var`获得下一个省略符形参中的数据，返回`NextVal_Type`类型的当前数据。若在省略符形参中无更多实参时调用`va_arg`，则行为未定义

- 释放`va_list`变量占用的空间，避免内存泄露

  ```c
  va_end(va_var);
  ```




### 3. 命令行参数

`main`函数的另一种形式如下：

```c
int main(int argc, char **argv);
// 或 int main(int argc, char *argv[]);
```

- `argc`：命令行参数的数量，命令行参数还包括程序名本身

  > 以`gcc`命令为例：`gcc -c -o main.c insert.c -o test`。
  >
  > 包括程序名`gcc`在内，以空白符为分隔，一共是 7 个参数，所以`argc`为 7

- `argv`：一个数组，每个元素都是一个`char`类型的指针，指向一个字符串，这些字符串中依次保存着命令行参数，`argv`数组的数量是`argc + 1`，因为最后一个元素还保存着一个 NULL 指针用于标志数组结束

  > 需要注意的是`argv`并不是二维数组，而是`char *`类型的数组，所以才可以使用指向指针的指针这样的参数形式。每一个`char *`元素确实指向一个字符串，也就是字符数组，但它们并不依存于`argv`这个数组中，而是离散的存在着，用一组`char *`指针联系在一起了而已。



## 三、函数指针

函数在赋值给一个同类型的函数指针时会自动转换为指针类型，在这种场景下，对函数加上取址运算符或是不加效果相同。

****

函数指针在使用的时候可以直接使用指针名而不需要解引用运算符，即对一个函数指针是否解引用效果是相同的。

****

函数指针首先是一个指针，其次才是函数，即指向函数类型的指针，而一个函数类型由两部分组成，一是返回类型，二是形参列表。所以声明一个函数指针时，首先保证其是一个指针，然后保证其指向的函数类型必须要有返回类型和形参列表。一个基本的形式是将`(*pToFunc)`作为函数名来看待：

```c
int (*pf)(int);
```

这就是一个最简单的函数指针。

下面是一个比较复杂的函数指针，接受一个函数指针作为形参，返回一个函数指针：

```c
int (*(*pf)(int (*pToFunArg)(int (*arr)[10]), int a))(float b);
```

- 函数指针：`pf`
- 形参
  - 其一：`int (*pToFunArg)(int (*arr)[10])`，一个函数指针，形参名为`pToFunArg`
  - 其二：`int a`
- 返回类型：`int (*)(float b)`

> 解释：
>
> - `pf`首先和`*`结合，是一个指针
> - `(*pf)`再和`(int (*pToFunArg)(int (*arr)[10]), int a)`结合，是一个函数，且形参为指向函数的指针和一个整型变量
> - `(*pf)(...)`再和`*`结合，表示返回值类型是一个指针
> - `(*(pf)(...))`再和`(float b)`结合，表示返回值这个指针类型是指向函数的，且形参为`float b`
> - 最后看到最前面的`int`，表示返回的这个指向函数的指针所指函数的返回类型是`int`类型
