## 一、联合类型

联合类型的定义形式和结构类型类型，看上去也定义了很多数据项，但一个联合类型变量在某一时刻只会是其中某一个数据项而并非同时具有多个数据项。

一个联合类型变量的尺寸和该类型中尺寸最大的一个数据项的尺寸相同，所有的数据项处在同一个内存位置。



## 二、声明和初始化

联合类型的声明和定义的方式完全类似于结构类型，区别仅在于`struct`和`union`两个关键字不同，此处不再详细说明。

- 可以使用和结构类型相似的方法初始化联合类型变量，即使用列表

  ```c
  union {
      int a;
      float b;
      char c[4];
  } x = {5};
  ```

  - 初始值必须是联合第一个成员的类型，而且它必须位于一对花括号里面，且这样的初始化只会初始化第一个成员
  - 列表中的初始值如果不是第一个成员的类型，那么它会转换为第一个成员的类型并赋值给第一个成员。如果转换不合法，那么将报错。

- 可以显式初始化其中某一个成员：

  ```c
  x.b = 3.14;
  ```

  - `x`这个变量的前 32 位内存将被初始化为`float`类型的`3.14`值



## 三、使用

一个联合类型的变量可以在每一次使用的时候按照不同的成员进行使用，例如：

```c
union {
    int a;
    float b;
    char c[4];
} x;

x.b = 3.14;
printf("%d\n", x.a);			// 将 x 按照 int 类型打印，实际值解释为 float 时为 3.14

printf("0x");
for(int i = 0; i < 4; ++i) {	// 将 x 解释为 4 个 char 类型，并依次打印每一个 char 元素的十六进制值
    printf("%x", x.c[i]);
}
```
