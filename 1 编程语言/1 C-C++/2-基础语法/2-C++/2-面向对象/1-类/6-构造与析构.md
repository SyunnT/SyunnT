## 一、构造函数

- 构造函数和普通函数不同。它声明在类内，没有返回类型，可以定义在类内或类外。定义时，在函数签名和函数体之间需要添加构造函数初始值列表，函数体通常用于分配堆内存而非一般初始化。

### 1. 构造函数初始值列表

在函数定义中处在参数列表之后，函数体的花括号之前的部分就是**构造函数初始值列表**，例如：

```cpp
// Type_Name 类的默认构造函数
Type_Name()
    : x(0), y(0)
    {}
```

- 构造函数初始值列表以冒号开头，每个成员的初始化表达式之间用逗号连接
- 每个成员的初始化表达式只能使用圆括号或花括号的形式，使用花括号时不接受带等号的形式
- 初始值可以是传入的参数，形参名可以和成员名相同，在构造函数初始值列表中也不用使用作用域运算符或`this`指针特别指出被初始化的成员，在圆括号或花括号初始化器之外考虑的名字不包括形参，而作为初始值的表达式则考虑形参
- 如果没有在构造函数的初始值列表中显式地初始化成员，先尝试用类内初始化初始化该成员，如果没提供类内初始值或编译器未实现则成员将在构造函数体之前执行默认初始化。如果是以下情况下的成员，则必须在构造函数初始值列表中进行初始化：
  - 当成员是`const`或者引用类型时且未提供类内初始值或编译器未实现类内初始值时
  - 当成员是某种类类型且该类没有定义默认构造函数，同时未提供类内初始值或编译器未实现类内初始值时
- 构造函数初始值中每个成员只能出现一次。成员的初始化顺序与它们在类定义中的出现顺序一致，构造函数初始值列表中初始值的前后位置关系不会影响实际的初始化顺序。



### 2. 委托构造函数

- 委托构造函数即构造函数初始值列表为另一个构造函数的构造函数，委托构造函数提供调用另一个构造函数需要的参数，例如：

  ```cpp
  class Sales_data
  {
  public:
      Sales_data(std::string s, unsigned cnt, double price)
          : bookNo(s), units_sold(cnt), revenue(cnt*price) { }
      
      Sales_data()
          : Sales_data("", 0, 0) { }
      Sales_data(std::string s)
          : Sales_data(s, 0, 0) { }
      
      Sales_data(std::istream &is)
          : Sales_data()
          { read(is, *this); }
  };
  ```

  第2、第3个构造函数委托第1个构造函数进行初始化；第4个构造函数委托第2个构造函数进行初始化。

  在此例中，前3个构造函数也可以写做同一个构造函数，每个参数提供对应的默认实参即可，但如果三个函数中某个函数需要的默认值不同时就不能用这种方法。

- 委托构造函数的优点是减少重复代码以及相似代码

- 构造函数可以嵌套，例如上述例子中的第4个构造函数



### 3. 隐式类类型转换

- 如果构造函数可以只接受一个实参，那么它同时定义了转换为此类类型的隐式转换机制，允许从参数类型向该类类型的隐式转换，此构造函数称为**转换构造函数**
- 只允许一步类类型转换。但对于内置类型的标准转换则没有这个限制
- 在构造函数前添加`explicit`关键字以阻止该隐式转换，`explicit`关键字只能在函数声明前添加。



### 4. constexpr 构造函数

- 字面值常量类的构造函数可以是`constexpr`函数。
- `constexpr`构造函数可以定义为`=default`或删除函数的形式。否则其必须既符合构造函数的要求（不能包含返回语句），又符合`constexpr`函数的要求（唯一能拥有的可执行语句就是返回语句），所以`constexpr`构造函数体一般来说应该是空的。
- 和`constexpr`的要求一样，在声明和定义前添加`constexpr`关键字即可。另外，`constexpr`构造函数必须初始化所有成员，初始值要么使用`constexpr`构造函数，要么是一条常量表达式



## 二、默认构造函数

- 一个调用时可以不接受任何参数的构造函数就是默认构造函数
- 默认构造函数将在不使用任何初始化器创建该类型对象时自动调用

### 1. 合成的默认构造函数

- 如果不提供任何构造函数，那么编译器提供一个合成的默认构造函数，其行为是：
  - 如果存在类内初始值，则用它来初始化成员
  - 否则，默认初始化该成员
- 使用`=default`取代构造函数初始值列表和函数体，显式使用编译器合成的默认构造函数
- 如果定义了任何构造函数但非默认构造函数，那么编译器不会合成默认构造函数，此时无法使用默认初始化，必须显式提供默认构造函数

### 2. 阻止默认构造函数的方法

- 以下情况下，合成的默认构造函数是删除的
  - 类的某个成员的析构函数是删除的或不可访问的
  - 类有一个引用成员且没有类内初始化器
  - 类有一个`const`成员，且没有类内初始化器且其类型未显式定义默认构造函数
- 使用`=delete`取代构造函数初始值列表和函数体，该函数将被定义为删除的，从而无法使用且对外为不可见



## 三、析构函数

- 函数名为波浪号`~`接类名构成，没有返回值，也不接受参数。函数用于销毁对象：

  ```cpp
  ~Foo();
  ```

- 析构函数的执行流程是：先执行函数体，然后销毁成员，成员按初始化顺序的逆序销毁（对于类类型的成员调用对应的析构函数）

- 析构函数通常什么也不用做，但如果对象管理了堆内存资源，那么析构函数就需要合理对该内存进行管理

- 析构函数在对象被销毁时自动调用

### 1. 合成析构函数

- 一个空函数体的典型析构函数
- 使用`=default`取代函数体，显式使用编译器合成的析构函数

### 2. 阻止析构函数的方法

> 当析构函数为删除的状态时，将不允许定义该类型的变量或创建该类的临时对象。对于删除了析构函数的类型，虽然不能定义这种类型的变量或成员，但可以动态分配这种类型的对象，但是不能释放这些对象。

- 可以将析构函数定义为`=delete`的
- 合成的析构函数在下面的情况下是删除的：
  - 类的某个成员的析构函数是删除的或不可访问的
