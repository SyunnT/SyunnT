## 一、基本概念

- 当使用基类的引用或指针调用一个虚函数时将发生动态绑定。
- 由于派生类对象包含基类对象，一个基类的指针或引用可以绑定到派生类对象上（实际上是派生类对象中的基类部分），称为**派生类到基类的转换**，且是隐式转换。（需要注意的是仅在派生类对象绑定给基类指针或引用时才允许此转换）
  若如此做，动态绑定在发生时就会绑定到实际传入的对象中的那个虚函数。

### 1. 回避动态绑定

- 即使当使用基类的引用或指针调用一个虚函数，也可以回避动态绑定行为的发生，方法是调用时在被调用的函数名前指明作用域：

  ```cpp
  double undiscounted = baseP->Quote::net_price(42);
  ```

  当派生类虚函数需要调用其基类版本时，就需要用到这种方法，否则调用的会是派生类自己正在重写的虚函数，导致无限递归。

### 2. 不可用转换情况

- 当派生类`public`继承于基类时，允许用户代码使用派生类对象向基类的指针或引用的转换；否则，不允许用户代码进行该转换
- 派生类的成员函数和友元永远都能使用派生类对象向基类指针或引用的转换而无论派生类以什么方式继承于基类
- 如果派生类1`public`或`protected`继承于基类，那么派生类1的派生类2的成员函数和友元可以使用派生类1对象向基类指针或引用的转换

### 3. 在派生类中改变基类成员的可访问性

- 除了非`public`继承外，也可以显式改变派生类中基类成员的可访问性，通过`using`声明实现，例如：

  ```cpp
  class Derived : private Base
  {
  public:
      using Base::size;
  protected:
      using Base::n;
  };
  ```

  也可以将原本`public`或`protected`的成员声明在其他的访问区域；
  派生类只能为那些它可以访问的名字提供`using`声明。

- 使用这种方法改变基类成员的可访问性不会影响动态绑定时的效果。例如：当基类中`public`的虚函数成员在派生类中被声明为`private`或`protected`的，对于用户代码来说，如果使用基类的指针或引用调用这个虚函数时，只要传入的对象允许转换规则，就可以调用到实际对象所处派生类中的对应虚函数版本。
