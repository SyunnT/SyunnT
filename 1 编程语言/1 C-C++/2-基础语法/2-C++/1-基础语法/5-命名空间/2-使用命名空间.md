## 一、命名空间别名

用下面的方法为一个命名空间指定别名：

```cpp
namespace new_name = old_namespace_name;
```



## 二、using 声明

一条`using`声明一次只引入命名空间的一个成员，如：

```cpp
using std::cout;
```

一条`using`声明语句可以出现在全局作用域、局部作用域、命名空间作用域以及类作用域中。在类作用域中，这样的声明语句只能指向基类成员

`using`声明将名字引入该声明所处作用域，并在作用域结束时取消引入该名字。



## 三、using 指示

`using`指示一次导入一整个命名空间内的成员：

```cpp
using namespace std;
```

和`using`声明不同，一条`using`指示一般被看作是将命名空间中的名字注入到最近的外层作用域中而非在所处作用域导入。但是和`using`声明相同的是，`using`指示的效果仍然是从该语句开始，直到离开`using`指示所处的作用域
