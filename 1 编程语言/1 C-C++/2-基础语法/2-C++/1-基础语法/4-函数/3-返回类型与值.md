## 一、返回值

- 函数不应返回局部对象的引用或指针
- 返回引用的函数将得到一个左值，可以放在赋值语句的左边
- 可以使用花括号包围的列表来返回值
  - 对于内置类型，列表中最多只能包含一个值。首先将创建一个返回类型的临时变量，然后进行对应的列表初始化，和正常的列表初始化相同，对初始值的要求更严格
  - 对于类类型，则由类本身定义初始值如何使用。首先会创建一个`std::initializer_list`的临时对象来保存这个列表，然后创建返回类型的临时对象，并用这个`std::initializer_list`对象进行初始化。



## 二、main 函数的返回值

- 如果`main`函数没有显式返回值，那么隐式返回 0



## 三、尾置返回类型

通过将返回类型写做`auto`并在末尾按规定格式写出实际的返回值类型就是使用尾置返回类型的过程：

```cpp
auto func(int i) -> int(*)[10];
```
