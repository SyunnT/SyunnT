## 一、基本语法

```cpp
template<Template_Para_list>
returnType functionName(Para_list)
{
    // ...
}
```

- `Template_Para_list`：模板参数列表，是一个逗号分隔的一个或多个**模板参数**的列表

- 模板参数：可以是**类型模板参数**，也可以是**非类型模板参数**

  - **类型模板参数**：使用`typename`或`class`加上类型名即可添加一个类型模板参数（`typename`和`class`没有区别，可以互换使用）

    ```cpp
    template<typename T>
    int compare(const T &v1, const T &v2)
    {
        if (v1 < v2) return -1;
        if (v2 < v1) return 1;
        return 0;
    }
    ```

  - **非类型模板参数**：使用特定的类型名加上变量名指定非类型参数

    ```cpp
    template<unsigned N, unsigned M>
    int compare(const char (&p1)[N], const char (&p2)[M])
    {
        return strcmp(p1, p2);
    }
    ```

- 返回类型：可以使用类型模板参数提供的类型及其复合类型作为返回类型

- 形参列表：可以使用类型模板参数提供的类型及其复合类型作为参数的类型

- 函数体：可以声明一个类型模板参数提供的类型及其复合类型的变量，以及进行相关的类型转换



## 二、实例化

- 调用一个**函数模板**时，不需要像调用类模板一样显式写出模板实参
- 编译器会根据调用时实际的模板实参代替对应的模板参数来创建出模板的一个“实例”

### 1. 类型模板参数的实例化

例如：

```cpp
// T 实例化为 int
cout << compare(1, 0) << endl;

// T 实例化为 vector<int>
vector<int> vec1{1, 2, 3}, vec2{4, 5, 6};
cout << compare(vec1, vec2) << endl;
```

- 需要注意的是类型会严格匹配，由于函数的参数列表表示的是两个相同类型的引用，所以调用也必须传入两个相同类型的对象，否则就会报错，例如：

  ```cpp
  cout << compare(1, 1.1) << endl;
  // 此调用会去匹配一个 compare(int, double) 的函数，但由于我们定义的函数模板不支持两个不同类型的实参输入，所以调用失败
  ```

- 实际传入的实参必须支持函数内使用的操作，在`compare`这个函数中，我们假设类型支持`<`运算符，所以调用时实参的类型必须支持`<`运算符

### 2. 非类型模板参数的实例化

例如：

```cpp
compare("hi", "mom");
```

`"hi"`和`"mom"`会传递给指向字符数组的引用（而非指向字符的引用），`N`和`M`刚好表示了两个数组的维度，根据两个字符串字面值可以得到`"hi"`的维度为 3，`"mom"`的维度为 4，所以实际就被实例化为了：

```cpp
int compare(const char (&p1)[3], const char (&p2)[4])
```

- 非类型参数会被一个用户提供的或编译器推断出的值所代替
- 一个非类型参数可以是一个整型，或者是一个指向对象或函数类型的指针或（左值）引用。
- 绑定到非类型整型参数的实参必须是一个常量表达式
- 绑定到指针或引用非类型参数的实参必须具有静态的生存期。指针参数也可以用`nullptr`或一个值为`0`的常量表达式来实例化
- 在模板定义内，模板非类型参数是一个常量值。在需要常量表达式的地方，可以使用非类型参数



## 三、模板实参推断

### 1. 类型转换

当模板函数的形参类型使用了模板类型参数，只有有限的几种类型转换会自动地应用于这些实参，其余的类型转换则不被允许，而是生成一个新的模板实例。以下类型转换是允许的：

- 顶层`const`：被忽略

- `const`转换：可以将一个非`const`对象的引用（或指针）传递给一个`const`的引用（或指针）形参

- 数组或函数指针转换：如果函数形参不是引用类型，则可以对数组或函数类型的实参应用正常的指针转换。

  > 如果函数形参是引用类型，那么数组不会转换为指针，引用类型会推断为一个具有具体维度的数组引用

**使用相同模板参数类型的函数形参**：一个模板类型参数可以用作多个函数形参的类型。由于只允许有限的几种类型转换，因此传递给这些形参的实参必须具有相同的类型。如果推断出的类型不匹配，则调用就是错误的。

### 2. 显式实参

- 对于无法接受实参进行推断的模板形参，每次调用都需要提供显式模板实参。显示模板实参在尖括号中给出，位于函数名之后，实参列表之前：

  ```cpp
  template<typename T1, typename T2, typename T3>
  T1 sum(T2, T3);
  
  // 调用
  auto val3 = sum<long long>(i, lng);		// T1 显式指定为 long long，T2、T3从函数实参类型推断而来
  ```

- 显示模板实参按从左只有的顺序与对应的模板形参匹配。根据此原则，如果必须提供显式模板实参的模板形参放在最右边的设计就很糟糕：

  ```cpp
  template<typename T1, typename T2, typename T3>
  T3 alternative_sum(T2, T1);
  ```

  这样的模板必须为所有三个形参指定实参。

### 3. 尾置返回类型与类型转换

- 有时，函数的返回类型可以从形参类型中得到，于是我们可以使用`decltype`获取一个形参构成的表达式的类型，但返回类型在形参之前，所以不能在此处使用`decltype`表达式，于是就需要使用尾置返回类型：

  ```cpp
  template<typename It>
  auto fcn(It beg, It end) -> decltype(*beg)
  {
      // ...
      return *beg;
  }
  ```

- 上述示例的返回类型是一个引用类型，如果我们不希望返回一个引用而是元素的值的拷贝，则需要借助标准库的类型转换（定义在`<type_traits>`头文件中）。

  此示例的具体解决方法是使用`remove_reference`类模板，它有一个模板类型参数和一个名为`type`的类型成员，具体用法如下：

  ```cpp
  typename remove_reference<decltype(*beg)>::type
  ```

  其中的`type`就是被引用的类型，也就是原类型。另外，为了使用模板参数的成员，必须使用`typename`

### 4. 函数指针和实参推断

- 当我们用一个函数模板初始化一个函数指针或为一个函数指针赋值时，编译器使用指针的类型来推断模板实参

- 如果不能从函数指针类型确定模板实参，则产生错误。除了前述的推断出的`T`不一致的情况外，还有以下情况：

  ```cpp
  template<typename T> int compare(const T&, const T&);
  void func(int(*)(const string&, const string&));
  void func(int(*)(const int&, const int&));
  
  func(compare);
  ```

  即，当函数指针作为一组重载函数的形参且根据此形参的区别进行重载匹配的时候

- 可以通过显式实例化解决这个问题：

  ```cpp
  func(compare<int>);
  ```

### 5. 模板实参推断和引用

- 当一个函数参数是模板类型参数的一个左值引用时（即，形如`T&`），那么只能传递给它一个左值。如果实参可以是`const`类型，那么`T`将被推断为`const`引用

  如果一个函数参数的类型是`const T&`，那么可以传递给它任何类型的实参。

- 当一个函数参数是一个右值引用时（即，形如`T&&`），可以传递给它一个右值，推断出的`T`的类型是该右值实参的类型

  如果给一个右值引用传入左值，那么`T`将被推断为实参的引用类型，例如如果传入的是`int`变量，那么`T`将被推断为`int&`，于是`T&&`得到一个引用的引用（`int& &&`），根据引用折叠规则，`int& &&`被折叠为`int&`。
  
  这样的推断规则可能对代码产生影响：
  
  ```cpp
  template<typename T> void func(T&& val)
  {
      T t = val;	// 不确定是拷贝还是对 val 的引用
      t = fcn(t);	// 如果是引用，那么传入的实参会被修改
      if (val == t) { /*...*/ }	// 如果是引用，则始终为 true
  }
  ```
  
  避免这个问题的方法是添加一个接受左值的重载函数：
  
  ```cpp
  template<typename T> void func(T&&);
  template<typename T> void f(const T&);
  ```
  
  

## 四、转发

部分函数的工作是进行转发，即将接受到的参数原封不动地转发给另一个函数进行处理。在这种情况下，如果参数的类型是一个非引用类型，那么就将进行传值调用，导致拷贝的发生，而后续如果要转发给一个接受引用的函数就无法获得想要的效果了。

所以转发函数的参数至少应该是引用类型的，除非确定后续的转发都是通过传值调用的。

- 可以将函数参数定义为一个指向模板类型参数的右值引用，可以保持器对应实参的所有类型信息：

  ```cpp
  template<typename F, typename T1, typename T2>
  void flip2(F f, T1 &&t1, T2 &&t2)
  {
      f(t2, t1);
  }
  ```

  - 可以保持传入参数的左值/右值性
  - 可以保持`const`属性

- 上述方法还有一个问题没有解决，如果在函数中被调用的函数是一个接受右值引用类型参数的函数，此时如果转发函数即使将一个右值引用传递给这个被转发的函数，仍然会导致左值传递给右值引用的错误，例如：

  ```cpp
  void innerFunc(T&& arg);
  
  void outerFunc(T&& param) {
      innerFunc(param);		// 错误
  }
  ```

  之所以错误，是因为函数形参即使是一个右值引用，它在函数内部也是左值（它有名字，可以取地址）。

  解决这个问题的方法是使用`std::forward`保持类型信息：

  ```cpp
  void outerFunc(T&& param) {
      innerFunc(std::forward<T>(arg));		// std::forward 必须通过显式模板实参来调用
  }
  ```

  - 当实参为右值时，`T`则为一个非引用类型，`forward<T>`将返回`T&&`
  - 当实参为左值，引发引用折叠，则`T`为一个左值引用类型，`forward<T>`返回一个左值引用的右值引用，再次引发引用折叠，返回一个左值引用类型
