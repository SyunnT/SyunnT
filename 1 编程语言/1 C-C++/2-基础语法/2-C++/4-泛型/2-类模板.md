## 一、基本语法

和函数模板类似：

```cpp
template<Template_Para_list>
class Class_Name
{
    // ...
};
```

- 成员函数可以定义在类模板内部，也可以定义在类模板外部。定义在类模板内的成员函数被隐式声明为内联函数

- 如果将成员函数定义在类外，那么定义的形式如下：

  ```cpp
  template<Template_Para_list>
  ret-type Class_Name<Template_Args_list>::member-name(para-list)
  ```

  和之前一样，如果`ret-type`是一个类内定义的类型，那么同样需要`Class_Name<Template_Args_list>`这样的前缀进行说明；而对于参数列表和函数体，由于函数名定义域已确定，所以后续的都可以直接使用而无需指明了

- 类模板的成员函数具有和模板相同的模板参数。因而，定义在类模板之外的成员函数必须以关键字`template`开始，后接类模板参数列表

- 在类模板作用域日内，可以直接使用模板名而不需要提供实参，例如：

  ```cpp
  template<Template_Para_list>
  class Class_Name
  {
  public:
      Class_Name() = default;
  };
  ```

  其中默认构造函数并不用写作：`Class_Name<Template_Args_list>() = default`。除构造函数外的其他地方与此类似



## 二、实例化类模板

- 实例化类模板必须提供额外信息，即**显式模板实参**列表，它们被绑定到模板参数
- 类只有在实例化时才生成实际的代码
- 类模板中成员函数只有当程序用到它的时候才进行实例化



## 三、友元

### 1. 类与友元间的友好关系

1. 如果一个类模板包含一个非模板友元，则友元被授权可以访问所有模板实例

   ```cpp
   template<typename T>
   class Test
   {
       friend void func();		// 友元 func 可以访问所有类模板实例的成员
       friend class Another;	// 友元 Another 可以访问所有类模板实例的成员
   };
   ```

2. 如果友元自身是模板，类可以授权给所有友元模板实例，也可以只授权给特定实例

   - 授权给所有友元模板实例的方法：友元包含模板声明

     ```cpp
     class Test
     {
         template<typename T> friend void func();		// 每个 func 实例都可以访问类成员
         template<typename T> friend class Another;		// 每个 Another 实例都可以访问类成员
     };
     ```

   - 授权给特定实例

     ```cpp
     // 由于两个友元都是模板的实例化，所以模板声明必须前置
     template<typename T>
     void func();
     
     template<typename T>
     class Another;
     
     class Test
     {
         friend void func<Spec_Type>();		// 只有 func 的特定实例 func<Spec_Type> 才能访问类成员，必须前置声明
         friend class Another<Spec_Type>;	// 只有 Another 的特定实例 Another<Spec_Type> 才能访问类成员，必须前置声明
     };
     ```

3. 如果类和友元都是模板，那么有以下情况：

   - 一对一友好关系：每个实例化的类模板对应一个实例化的友元

     ```cpp
     // 和上面一样，同样需要前置声明模板
     template<typename T>
     void func();
     
     template<typename T>
     class Another;
     
     template<T>
     class Test
     {
         friend void func<T>();		// 实例化为 func<Spec_Type> 的函数可以访问实例化为 Test<Spec_Type> 的成员
         friend class Another<T>;	// 实例化为 Another<Spec_Type> 的类可以访问实例化为 Test<Spec_Type> 的成员
     };
     ```

   - 多对一：将友元的模板实参改为某种特定类型即可

   - 多对多：

     ```cpp
     template<T>
     class Test
     {
         template<typename X> friend void func();		// 此处的模板形参不能和 Test 的模板形参同名
         template<typename X> friend class Another;		// 同上
     };
     ```

   - 一对多：在特例化的模板类里面添加友元即可

### 2. 模板类型形参作为友元

```cpp
template<typename T>
class Test
{
    friend T;
};
```

- 友元可以是内置类型



## 四、别名

- 可以为类模板定义一个类型别名，例如：

  ```cpp
  template<typename T> using twin = pair<T, T>;
  
  // 使用
  twin<string> authors;		// 实际类型为 pair<string, string>
  ```

- 当我们定义一个模板类型别名时，可以固定一个或多个模板参数，例如：

  ```cpp
  template<typename T> using partNo = pair<T, unsigned>;
  
  // 使用
  partNo<string> books;		// 实际类型为 pair<string, unsigned>
  ```



## 五、静态成员

- 类模板中同样可以声明和定义静态成员，和其他成员一样，当类模板实例化之后才会生成实际的代码，每一个实例化的类中都有一个对应的静态成员

- 对于静态数据成员，仍然需要定义在类外，此时需要通过和定义类外的成员函数相同的方式进行访问：

  ```cpp
  template<typename T>
  type Class_Name<T>::static_data_member = init_value;
  ```



## 六、成员模板

类模板中的成员函数也算是某种意义上的模板函数，但是它的模板形参是依赖于类的模板形参的。而我们也可以定义不依赖与类模板的模板成员函数，叫做**成员模板**。

- 普通类的成员模板：和一般模板函数相同，在调用时隐式推导模板形参的类型从而进行调用

- 类模板的成员模板：成员模板的模板形参不能和类模板相同：

  ```cpp
  template<typename T>
  class Blob
  {
      template<typename It>
      Blob(It b, It e);
  };
  ```

  当这样的成员函数在类外定义时需要同时为类模板和成员模板提供模板参数列表：

  ```cpp
  template<typename T>
  template<typename It>
  Blob<T>::Blob(It b, It e)
  {
      // ...
  }
  ```
