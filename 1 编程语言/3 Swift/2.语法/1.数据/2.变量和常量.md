## 变量

### 声明

Swift 中使用`var`关键字声明变量：

```swift
// 初始化声明
var var1 = 10
var x = 0.0, y = 0.0, z = 0.0		// 多变量同类型
var i = 10, j = 3.14, k = true	// 多变量不同类型
// 非初始化声明
var var2: Int
var x, y, z:Int									// 多变量同类型
var i: Int, j: Double, k: Bool	// 多变量不同类型
// 混合（不常用）
var i: Int = 10, j: Double = 3.14
```

- 变量在声明时必须有类型信息，可以通过提供初始值的方式进行推断，也可以直接写明类型，也可以同时提供类型和初始值。后续无法再修改类型
- 变量在使用前必须进行至少一次赋值，即必须进行初始化。Swift 变量不存在默认值
- 一条声明语句中可以同时声明多个变量，每个变量可以是相同类型也可以不同类型
  - 当提供初始值时，需要为每个变量都提供初始值；当提供类型时，只在最后一个变量提供类型即可，也可以为每个变量都提供类型
  - 一条多变量声明语句中可以为不同变量分别提供初始值或类型



## 常量

### 声明

Swift 中使用`let`关键字声明常量：

```swift
let ci = 10;
// 其余声明方式略
```

- 常量的声明形式和变量基本一致，故略去
- 即使是常量，也可以不在声明时提供初始值，只要在使用前必须进行初始化即可
- 和其他语言的常量一样，一个常量只能在初始化时赋值一次



## 命名

- 常量和变量名几乎可以包含任何字符，包括 Unicode 字符：

  ```swift
  let π = 3.14159
  let 你好 = "你好世界"
  let 🐶🐮 = "dogcow"
  ```

- 常量和变量名不能包含空格、数学符号、箭头、专用的 Unicode 标量值，或画线和画框字符

- 常量和变量名也不能以数字开头

- 可以用关键字作为变量或常量名，但需要在用到该名字时用反引号包裹：

  ```swift
  let `let` = 10
  print(`let`)
  ```
