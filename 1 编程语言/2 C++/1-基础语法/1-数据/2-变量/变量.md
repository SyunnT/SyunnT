变量声明的基本格式为：

```
<type> 
<declarator_1> [initializer],
<declarator_2> [initializer],
...
<declarator_n> [initializer];
```

- `type`：任何基本类型或者类类型
- `declarator`：标识符和一个可选的类型说明符（`*`、`&`、`&&`、`[]`）
- `initializer`：可选的初始化器，有多种初始化器可选。如果不使用显式初始化器，那么变量被默认初始化。某些类型不允许默认初始化。



## 一、声明与定义

对于变量而言，当它被声明时通常就被定义了，即分配内存并确定其值。

- 某些类型包括某些类类型，不允许默认初始化，所以必须进行显式初始化该类型才被定义
- 除此之外的其他类型包括类类型在声明时就被定义了，如果提供了初始化器，就用初始值来初始化它，否则进行默认初始化
- 对于不提供初始化器的`extern`声明，仅为声明而非定义。若`extern`声明提供了初始化器，那么此处为定义。

### 1. 标识符

C++ 的标识符由字母、数字、下划线组成，但不能以数字开头。标识符的长度没有限制，对大小写字母敏感。同时不能使用关键字作为标识符



### 2. 初始化

#### 1）初始化器

```cpp
// 1. 拷贝初始化格式
= expression
    
// 2. 列表初始化格式
= {}
= { initializer-list }
{}
{ initializer-list }

// 3. 直接初始化格式
( initializer-list )
```

- `expression`：任何表达式（除了不带括号的逗号表达式）
- `initializer-list`：以逗号分隔的初始化子句列表，初始化子句可以是：
  - `expression`
  - `{}`
  - `{initializer-list}`



#### 2-1）默认初始化

**形式**：

- 一个对象如果没有使用任何初始化器，这个对象就进行**默认初始化**。

**效果**：

- 如果类对象被默认初始化，那么调用对应的默认构造函数进行初始化
- 如果数组被默认初始化，则数组的每个元素都进行默认初始化
- 自动存储器的变量不执行初始化
- 静态存储器的变量进行零初始化

**注意**：

- 引用和`const`标量对象不能默认初始化



#### 2-2）拷贝初始化

**形式**：

```cpp
// 1
T object = other;				// other用于初始化 T 类型对象
// 2
f(other);						// other用于初始化函数形参
// 3
return other;					// other用于初始化函数返回类型的临时量
// 4
throw object;
catch (T object);				// throw出的object用于初始化catch中的T类型object
// 5
T array[N] = {other-sequence};	// 对array中的每个元素执行拷贝初始化
```

**行为**：

- 若`T`是一个类类型，然后`other`在没有`cv`限定时的类型为`T`或者继承于`T`，则会调用`T`类型中的拷贝或移动构造函数来初始化对象（必须是非显式的函数）
- 若`T`是一个类类型，但`other`不为`T`类型或继承于`T`，或`T`不是一个类类型，但`other`是一个类类型。如果用户定义了从`other`的类型到`T`类型的转换，则会调用对应的转换函数来初始化对象，首先将`other`转换为`T`，其结果是一个纯右值中间对象，然后再调用对应的拷贝或移动构造函数初始化对象。
- 否则，如果需要的话，就对`other`进行标准转换为`T`类型后用于初始化对象

**注意**：

- 数组不允许拷贝



#### 2-3）列表初始化

**形式**：

```cpp
// 直接列表初始化
T object{arg1, arg2, ...};
T{arg1, arg2, ...};
// 拷贝列表初始化
T object = {arg1, arg2, ...};
f({arg1, arg2, ...});			// 列表实参初始化形参
return {arg1, arg2, ...};		// 列表返回值初始化函数调用临时量
```

**效果**：

- 特例：

  - 如果被初始化对象类型是**聚合类**且花括号初始化器列表具有**相同或派生类型的单个初始化器子句**，则从该初始化器子句初始化对象（对于拷贝列表初始化，通过**拷贝初始化**；对于直接列表初始化，通过**直接初始化**）

    > 花括号列表中只有一个相同或派生类型的聚合类对象

  - 否则，如果被初始化类型是**字符数组**且花括号初始化器列表**具有适当类型的字符串字面量的单个初始化器子句**，则数组如寻常般从字符串字面值量初始化

    > 花括号列表中只有一个字符串字面量

- 聚合类

  - 否则，如果被初始化类型是**聚合类型**，则执行**聚合初始化**

- 非聚合类的类类型

  - 否则，如果**花括号初始化器列表为空**且被初始化类型**具有默认构造函数**，则执行**值初始化**

  - 否则，则考虑：
    - 如果所有接受`std::initializer_list`作为唯一实参或作为首个实参且剩余实参具有默认值的构造函数参与重载决策并匹配
    - 如果上述情况未产生匹配，则将花括号中的所有初始化器作为实参考虑调用被初始化类型的匹配的构造函数，限制是只允许**非窄化转换**

- 非类类型

  - 否则，如果花括号初始化器列表只有一个初始化器子句，且被初始化类型不是引用类型，或是其所引用的类型与初始化器子句的类型相同或为其基类的引用类型，则进行**直接初始化**（在直接列表初始化中）或**拷贝初始化**（在拷贝列表初始化中）。限制是**不允许窄化转换**

  - 否则，如果被初始化类型是与初始化器子句的类型不兼容的引用类型。当引用是`const`左值引用时，创建一个纯右值临时量并用初始化器**对该临时量进行拷贝列表初始化**，并将引用绑定到该临时量

  - 否则，如果花括号初始化器**没有初始化器子句**，则`T`为**值初始化**。




#### 2-4）直接初始化

**形式**：

```cpp
// 1
T object(arg);
T object(arg1, arg2, ...);
// 2
T(arg);
T(arg1, arg2, ...);
// 3
static_cast<T>(other);
// 4
[arg]() { ... };
```

**效果**：

- 如果`T`是一个数组类型，则程序错误
- 如果`T`是一个类类型，在所有构造函数中选出最佳匹配并对对象进行初始化
- 如果`T`不是类类型，但初始值的类型是类类型，如果存在从该类类型或其基类类型向`T`类型的转换，则将先进行转换然后其值用于初始化对象
- 否则，如果需要的话，执行标准转换并初始化对象



#### 3-1）值初始化

**形式**：

```cpp
T();
T{};
T object{};		// 相比于圆括号，这种形式不会被认为是函数声明，所以可用于值初始化
```

**效果**：

- 如果使用花括号`{}`，那么当`T`是聚合类型（数组或聚合类）时，将执行**聚合初始化**
- 否则，如果使用花括号`{}`，且`T`是一个类类型，且没有默认构造函数但有一个接受`std::initializer_list`类型的构造函数，那么将执行**列表初始化**
- 否则，当`T`是一个类类型（包括聚合类）时，进行分为下面两步的**值初始化**
  - 如果默认初始化对应着该类型的一个构造函数，并且该构造函数并非用户提供的，那么这个对象先进行零初始化
  - 然后执行默认初始化
- 否则，对象被零初始化

**注意**：

- 引用不能被值初始化

## 三、存储期与链接

每个声明可以有一个存储类说明符，它控制名字的存储期与链接属性。

> 例外：
>
> - `thread_local`可以和`static`/`extern`一起出现
> - `mutable`不控制名字的存储期

存储期包括：

- 静态存储期：存储持续程序的整个生命周期。

  > 属于命名空间作用域的变量默认具有静态存储期。

- 线程存储期

- 自动存储期

- 动态存储期

链接包括：

- 外部链接
- 内部链接
- 无链接

存储类说明符包括：`register`、`static`、`thread_local`、`extern`、`mutable`

### 1. register

- 可用于**块作用域中的非类成员的变量声明**和**非类成员函数中的形参声明**，`register`作为一个提示，表明声明为`register`的变量将被大量使用，其值可以存储在 CPU 寄存器中。该提示可以被忽略



### 2. static

- 可用于**非类成员的变量声明**、**命名空间作用域下非类成员的函数声明**以及**类成员声明**：
  - 非类成员的变量声明：静态存储期
  - 命名空间作用域下非类成员的函数声明：
  - 类成员声明：静态成员



### 3. thread_local

- 可用于**非类成员的变量声明**以及**类成员的静态变量声明**。`thread_local`使这些变量具有线程存储期



### 4. extern

- 可用于**非类成员的变量声明**和**非类成员的函数声明**
