### 2. 别名声明

**语法**：

```cpp
using new_type = other_type;
```

> 使用该方法，首先需要提取出旧类型，基本上的提取方法就是先写出该类型的完整声明，然后去掉标识符，剩下的就是该声明的类型。例如，一个函数指针的数组类型：
>
> ```c
> void (*fparr[20])(void);
> // 将标识符去除并进行别名声明
> using new_type = void(*[20])(void);
> ```

**注意**：

- 当`const`修饰一个别名类型时，修饰的是这个类型最本质的那个性质，以指针的别名为例，`const`修饰的则是指针本身，因为它本质是指针。



## 二、`auto`推导

可以用`auto`取代变量声明中的类型，如下：

```cpp
auto
<declarator_1> [initializer],
<declarator_2> [initializer],
...
<declarator_n> [initializer];
```

- `auto`使用初始值来推导其所代表的类型，所以用`auto`声明的变量必须初始化

- 如果初始值是一个列表初始化器，那么`auto`为`std::initializer_list<type>`类型，其中`type`是列表初始化器中每一个初始值的类型，每个初始值都必须有相同类型

- 数组名作为初始值时，首先会自动退化为指向元素类型的指针，然后`auto`据此推导为指针

- 当引用被用作初始值时，编译器将以引用对象的类型作为`auto`的类型。如果要创建一个引用，就在变量名前添加`&`符号。

- `auto`会去除初始值中的顶层`const`，但保留底层`const`（对指针而言）。如果需要一个顶层`const`属性，那么就手动在`auto`前添加`const`关键字。
  对于引用而言，如果添加了`&`符号说明自己声明的是一个引用类型变量，那么当初始值是一个常量对象时，此时的`auto`也会自动添加常量属性；如果是一个字面值或常量表达式，则不会添加常量属性，需要手动添加

- 对于已经推导出结果的`auto`来说，如果其中含有`const`、`&`、`*`等关键字或符号，可以再显式写一次，`auto`中所含的这些关键字或符号如果显式写出了，就从`auto`中剔除对应的关键字或符号。`const`添加在`auto`前，而`&`、`*`等符号则添加在变量名的前面。

- 当在一条`auto`声明语句中声明创建多个变量时，需要保证每个初始值都能够使`auto`代表完全相同的内容，否则程序错误，例如：

  ```cpp
  const int ci = 10;
  auto i = ci, &ri = ci;			// 错误：对 i 来说 auto 是 int，而对 ri 来说 auto 是 const int
  const auto i = ci, &ri = ci;	 // 正确，显式添加 const 之后，ri 仍然是 const int & 类型，此时两种类型得到的 auto 相同
  auto ival = 10, dval = 3.14;	 // 错误：不会因为 auto 先判断为 int 后面的 dval 就先将 3.14 转换为 int，而是导致推断类型不一致
  ```

  

## 三、decltype 类型指示符

**语法**：

```cpp
decltype(expression) <spec> [initializer];
```

- `decltype`用`expression`值的类型作为实际的类型，所以初始值为非必要。
- `expression`不会进行求值，只使用其值的类型
- 推导规则
  - `expression`如果是一个变量，那么`decltype`返回该变量的类型（包括顶层`const`和引用在内）
  - 否则，如果当`expression`是一个能作为一条赋值语句的左值时，返回该表达式值类型的引用（包括在变量外套了一层括号的情况）
  - 否则，返回表达式值的类型
