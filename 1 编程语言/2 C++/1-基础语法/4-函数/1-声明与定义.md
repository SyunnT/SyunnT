## 一、函数签名

函数也可以看作一个有类型的标识符，它的类型就是**函数签名**除去函数名之外的部分。

而函数签名则是函数声明去掉形参名之后的样子：

```cpp
ret_type func(para_type_lsit);
// 例如：
int retn(int, int);
```

而它的类型就是:

```cpp
using func_type = int(int, int);
```

不过通过使用`func_type`声明的函数无法进行定义，所以声明和定义函数通常不使用类型别名

一个函数指针的类型是：

```cpp
using pToFunc_type = int (*)(int, int);
```



## 二、声明

- 每一个函数的声明和定义通常都在所有函数外，具有外部链接属性。在函数内只能对函数进行声明而不能进行定义，并且如果函数内声明的函数与外层作用域声明的函数同名，那么外层的同名函数将被屏蔽
- 在调用函数的时候，在调用点之前必须有一个可见的匹配的函数声明
- 如果仅声明函数，那么写出该函数的函数签名即可，并不需要形参名
- 形参列表为空时，可以直接简单的不写或者写一个`void`



## 三、定义

- 如果返回值类型不为`void`，那么必须在函数结束时返回值，使用`return value;`语句
- 如果返回值类型为`void`，那么也可以使用`return`语句来结束函数



## 四、`noexcept`

- 在函数的参数列表之后函数体之前添加
- 声明和定义都需要
