## 一、基本概念

- 重载运算符的名字由`operator`和其后要定义的运算符号共同组成

- 重载运算符函数的参数数量与该运算符作用的运算对象数量一样多。
  左侧运算对象传递给第一个参数，而右侧运算对象传递给第二个参数。
  若一个运算符函数是成员函数，则它的左侧运算对象绑定到隐式的`this`指针上
  （`+`、`-`、`*`、`&`）四个符号可以是一元运算符也是二元运算符，从参数的数量可以推断定义的是哪种运算符

- 对于一个运算符函数来说，他要么是类的成员，要么至少含有一个类类型的参数，否则错误

- 只能重载已有的运算符

- 除了重载的函数调用运算符`operator()`之外，其他重载运算符不能含有默认实参

- 对于一个重载的运算符来说，其优先级和结合律与对应的内置运算符保持一致

- 可重载运算符：

  ```
  +		-		*		/		%		^
  &		|		~		!		,		=
  <		>		<=		>=		++		--
  <<		>>		==		!=		&&		||
  +=		-=		/=		%=		^=		&=
  |=		*=		<<=		>>=		[]		()
  ->		->*		new		new[]	delete	 delete[]
  ```

- 不可重载运算符

  ```
  ::		.*		.		?:
  ```

### 1. 运算符函数的调用

- 可以像使用内置类型一样通过一般的表达式来间接调用运算符函数

- 像调用普通函数一样显式直接调用运算符函数：

  ```cpp
  operator+(data1, data2);
  ```

  对于成员函数来说，直接调用的形式和其他成员函数调用方式一样，在前面加上对象名和调用符即可

### 2. 即使可以也不建议重载的运算符

- `||`、`&&`、`,`几个运算符关于运算对象求值顺序的规则无法保留，且`&&`、`||`运算符的短路求值属性无法保留
- 取地址运算符`&`和逗号运算符`,`已经有用于类类型对象时的特殊含义了

### 3. 和原运算符特征一致

- 如果类执行 IO 操作，则定义移位运算符使其与内置类型的 IO 保持一致
- 如果类的某个操作是检查相等性，则定义`operator==`和`operator!=`
- 如果类包含一个内在的单序比较操作，则定义`operator<`和其他关系操作
- 重载运算符的返回类型通常情况下应该与其内置版本的返回类型兼容：
  - 逻辑运算符和关系运算符应该返回`bool`
  - 算术运算符应该返回一个类类型的值
  - 赋值运算符和复合赋值运算符应该返回左侧运算对象的一个引用

### 4. 赋值与复合赋值

- 如果类含有算术运算符或者位运算符，最好也提供对应的复合赋值运算符

### 5. 选择作为成员或者非成员

- 赋值（`=`）、下标（`[]`）、调用（`()`）和成员访问箭头（`->`）运算符必须是成员
- 输入输出运算符（`<<`、`>>`）必须是非成员函数
- 复合赋值运算符一般来说应该是成员，但并非必须
- 改变对象状态的运算符或者与给定类型密切相关的运算符，如递增、递减和解引用运算符，通常应该是成员
- 具有对称性的运算符可能转换任意一端的运算对象，例如算术、相等性、关系和位运算符等，因此它们通常应该是普通的非成员函数



## 二、输入和输出运算符

### 1. 重载输出运算符（`<<`）

- 第一个形参是非常量`ostream`对象的引用；第二个形参通常是一个常量引用，引用类型是需要打印的类类型
- 返回类型和第一个形参类型相同，`operator<<`一般返回它的`ostream`形参
- 输出运算符尽量减少格式化操作

### 2. 重载输入运算符（`>>`）

- 第一个形参是运算符将要读取的流的引用，通常是非常量`istream`类型的引用；第二个形参是将要读入到的非常量对象的引用
- 返回类型和第一个形参相同，`operator>>`一般返回它的`istream`形参
- 输入运算符需要处理输入可能失败的情况：
  - 当流含有错误类型的数据时读取操作可能失败
  - 当读取操作到达文件末尾或者遇到输入流的其他错误时也会失败



## 三、算术和关系运算符

### 1. 算术运算符

- 算术运算符通常会计算它的两个运算对象并得到一个新值，这个新值不是任意一个运算对象，常常位于一个局部变量之内，操作完成后返回该局部变量的副本作为其结果
- 如果类定义了算术运算符，则它一般也会定义一个对应的复合赋值运算符
- 通常使用复合赋值运算符来实现对应的算术运算符

### 2. 相等运算符

- 如果一个类含有判断两个对象是否相等的操作，则它应该把函数定义成`operator==`而非一个普通的明明函数
- 如果类定义了`operator==`，则该运算符应该能判断一组给定的对象中是否含有重复数据
- 通常情况下，相等运算符应该具有传递性
- 如果定义了`operator==`，那么这个类也应该定义`operator!=`
- 相等运算符和不相等运算符中的一个应该把工作委托给另外一个
