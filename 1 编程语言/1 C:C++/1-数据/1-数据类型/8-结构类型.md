## 一、结构类型

### 1. 类型

**结构类型**即使用`struct`定义的类型，在声明完成之后可以在仅使用其名字的地方使用，在定义完成之后才能完全的访问该类型。

结构变量属于标量类型，因此可以像对待其他标量类型那样执行相同类型的操作。结构也可以作为传递给函数的参数，它们也可以作为返回值从函数返回；相同类型的结构变量相互之间可以赋值。可以声明指向结构的指针，取一个结构变量的地址，也可以声明结构数组。



### 2. 尺寸与内存对齐

结构类型是用已知的类型构建的新类型，一个结构类型变量的尺寸由其数据项类型和是否进行内存对齐决定：

- 如果不进行内存对齐，那么这个结构类型的变量所占用的内存空间就是所有数据项的`sizeof`值相加

- 如果进行内存对齐，那么这个结构类型的变量在按顺序且进行内存对齐放置后总占用的尺寸，包括浪费的空间

  > **内存对齐**：如果不进行内存对齐，那么程序想要访问一个数据，则很有可能需要访问两次，因为不能保证每一次访问该数据的时候，访问的字节位置刚好是该数据的起始字节位置。所以进行内存对齐是为了提高访问数据的速度
  >
  > **内存对齐的方式**：对于一个结构来说，首先找出其中尺寸最大的数据项，整个结构所占用的尺寸就是这个数据项的尺寸的整数倍。然后在这样一段内存中，每一个数据项只能放在该数据项尺寸的整数倍的内存位置，按照在结构中的声明的顺序进行放置

## 二、声明、定义与初始化

### 1. 通用声明

```c
struct Type_Name { member-list } variable-list;
```

- `struct`：表示这是一个结构声明
- `Type_Name`：结构名，可选。如果这个结构仅使用一次或在定义这个结构时就使用`typedef`重新取了别名则通常可以省略
- `{member-list}`：成员列表，可选。只在第一次定义该结构时使用即可
- `variable-list`：变量列表，可选。既可以在定义的同时使用，也可以在后续声明时使用

> 两个具有相同成员列表的结构不是同一种类型。
>
> 注意末尾的分号，无论何种方式的结构声明或定义都需要分号结尾

****

**典型示例**：

- **省略结构名**：

  ```c
  // 如果该结构仅使用一次，则通常以这种方式声明结构变量
  struct {
      int a;
      char b;
      float c;
  } x;
  ```

  ```c
  // 如果在声明时就使用typedef取别名，也可以省略结构名
  typedef struct {
      int a;
      char b;
      float c;
  } Simple;		// 需要注意的是，此时为 typedef 声明语句，不能在定义结构的同时声明结构变量，Simple 是这个结构的别名
  Simple x;		// 直接使用 Simple 作为类型名
  ```



### 2. 结构成员

结构成员可以是标量、数组、指针以及其他定义完成的结构，也可以是任何已声明但未定义完成的结构的指针，如：

```c
struct SIMPLE {
    // 标量、数组、指针
    int i;
    char a;
    float b;
    char *str;
    short arr[N];
};

struct UNCOMP;

struct COMPLEX {
    // 已完成的结构可以创建变量或指针
    struct SIMPLE s;
    struct SIMPLE *ps;
    // 未完成的结构只能创建指针
    struct UNCOMP *pu;
    // 本结构只能创建指针
    struct COMPLEX *pc;
};
```



### 3. 初始化

结构的初始化也可以使用初始值列表：

```c
struct INIT_EX {
    int a;
    short b[10];
    Simple c;
} x = {
    10,
    {1, 2, 3, 4, 5},
    {25, 'X', 1.9}
};
```

#### 初始化器（C99）

可以使用初始化器来初始化结构成员，例如：

```c
struct INIT_EX {
    int a;
    short b[10];
    Simple c;
} x = {
    .b = {1, 2, 3, 4, 5},
    .a = 10
};
```



### 4. 不完整声明

在部分需要先使用再定义的情形下，可以使用结构的不完整声明，如：

```c
// 作为类型的前向声明，可以省略成员列表
struct B;

struct A {
    struct B *partner;
};

struct B {
    struct A partner;		// B 中需要 A 作为成员，所以需要先定义 A，但定义 A 需要先有 B 的名字，即先声明 B
};
```

## 三、操作

### 1. 访问成员

一个结构类型的变量可以访问其成员，一个结构类型的指针可以访问其指向变量的成员，不过它们使用的运算符不同：

```c
struct Simple {
    int i;
    float f;
    char str[2];
};

struct Simple s, *ps = &s;

s.i = 0;
ps->f = 0.0;
s.str[0] = 'a';
ps->str[1] = '\0';
```



### 2. 结构类型函数形参

结构变量可以直接作为参数传递给函数，因为它支持拷贝。而数组不能拷贝，所以只能借助指针进行传递。

但直接传递结构变量的效率并不高，因为它的数据项越多，需要做的拷贝工作就越多，通常结构类型变量仍然使用指针进行传递。



### 3. 拷贝

和数组不同，结构体可以直接拷贝，前提是它们是同一种结构体类型。

需要注意的是，两个成员完全相同的结构体类型并不算同一种类型。



## 四、复合字面量（C99）

和数组的复合字面量类似，也是`(类型){初始值列表}`的写法，不过这里的类型应该是一个结构类型，且初始值列表。例如:

```c
struct book {
    char title[MAXTITL];
    char author[MAXAUTL];
    float value;
};

(struct book) {"Crime and Punishment", "Fyodor Dostoyevsky", 11.25};
```

## 六、匿名结构成员（C11）

如果结构体中一个成员也是结构，则可以将其定义为匿名结构：

```c
struct person {
    int id;
    struct {
        char first[20];
        char last[20];
    };
};
```

初始化这样的结构还是和之前一样：

```c
struct person ted = {8483, {"Ted", "Grass"}};
```

访问这个结构体中的成员时，可以将匿名结构体的成员作用域看作暴露在内层匿名结构体外：

```c
puts(ted.first);
```
