## 一、指针类型

### 1. 类型

- **用途**：用来保存一个内存地址，且可以对该地址的内容进行访问修改等操作
- **实现**：对于一个 32 位的程序，指针也是 32 位的整数；对于一个 64 位的程序，指针也是 64 位整数

### 2. 字面值

指针类型严格来说并没有字面值，硬要说的话`NULL`可以算一个，但实际上`NULL`是对 0 进行强制类型转换为`void*`后定义的宏



## 二、类型转换与允许值

### 1. 指针值

指针的指针类型值可以是`NULL`（`void*`）或者对同类型变量进行取地址得到的值，其类型是指向该变量类型的指针，如果是对一个常量取地址，则得到的是一个常量指针。

- `void*` —— 其他指针：支持隐式转换
- 其他指针 —— `void*`：支持隐式转换
- 不同类型指针间的转换：不允许隐式转换（部分编译器默认只给出警告）
- 指针常量 —— 非指针常量：无类型转换存在，忽略指针常量的常量性
- 非指针常量 —— 指针常量：无类型转换存在，忽略指针常量的常量性
- 常量指针 —— 指向非常量的指针：不允许隐式转换（部分编译器默认只给出警告）
- 指向非常量的指针 —— 常量指针：支持隐式转换



### 2. 整数值

指针只允许 0 这一个整数值直接作为指针的值，即仅 0 可以隐式转换为指针类型。

- 整数值 —— 指针：不允许隐式转换（部分编译器只给出警告）

  > 此处的整数值包括字符类型



### 3. 浮点值

- 浮点值 —— 指针：转换不合法



### 4. 数组

- 数组 —— 指针：多数时候，数组会直接转换为指向其第一个元素的指针，若数组声明为`register`，则行为未定义。除以下情况之外：
  - 作为取值运算符的操作数
  - 作为`sizeof`的操作数
  - 作为用于数组初始化的字符串字面量

> 一个多维数组的转换会转换为指向数组的指针而非指向指针的指针，例如，对于一个二维数组`int arr[3][3]`而言：
>
> - `arr`会转换为`int (*parr)[3]`
> - 而`arr[n]`会转换为`int *pi`
>
> 但`arr`不会转换为`int **ppi`，也不能用`int **ppi`来指向一个二维数组，因为当我们对`ppi`使用如下表达式的时候：
>
> ```c
> ppi[1];
> ```
>
> 会出现错误，因为`ppi[1]`等价于`*(ppi + 1)`，此时`ppi`的偏移量为一个指针的尺寸而并非二维数组中数组元素的尺寸



## 三、操作

### 1. 声明和初始化

#### 声明

指针的声明需要用到说明符`*`，例如：

```c
int *p;
```

其中，`p`就是一个指向`int`类型的指针，其中说明符仍然是`int`而不是`int*`，声明表达式列表则是`*p`，表示`p`是一个指针，由于在声明时`*`符号是和标识符结合，所以我们可以像下面这样声明：

```c
int *p, i;
```

其中`p`是指针，但`i`只是一个`int`类型的整数，因为没有`*`与`i`结合。

但是我们在描述一个指针变量的类型时，仍然使用类似于`int*`一样的形式来表示。例如，当我们要对一个指向`int`的指针执行`sizeof`时，就应该使用：

```c
sizeof(int*);
```

#### 常量与指针

指针本身是一个变量，其所指的对象也是一个变量，所以在声明一个需要用`const`修饰的指针时，我们可以分别对这两部分进行限定，下面是对两部分都进行限定的例子：

```c
const int *const pi = NULL;
```

其中，后者用于修饰指针变量本身是常量，即不可指向其他对象；而前者用于修饰指针所指的对象是常量，我们则无法通过该指针对其所指的对象进行修改等写操作。

#### 初始化

对于一个自动存储期的指针来说，如果不显式初始化，那么其值可能是垃圾值；对于静态存储期的指针，其值被默认初始化为`NULL`。

对于一个指针常量来说，由于定义完成之后就无法再修改其值，所以最好在声明的同时初始化。C 语言允许指针常量不显式初始化，但其将可能指向内存中任意位置。

#### 指向指针的指针

如：

```c
int **ppi = NULL;
```





### 2. 间接访问

使用解引用运算符可以访问指针所指内存位置中的内容：

```c
int i = 42;
int *p = &i;

*p = 30;
```

如上所示：`*p`即`p`指针所指内存位置中的内容，其实际意义是一个`int`类型的变量

> 需要注意的是，`*p`的实际意义并不是因为`int i = 42`这条语句得到的，而是由`p`的类型得到的。例如：
>
> ```c
> double dval = 3.14;
> int *pi = (int*)&dval;
> ```
>
> 上面的这个`pi`实际上指向的位置是一个`double`类型的变量，但`*pi`的实际意义却是一个`int`类型的变量
>
> 所以对指针解引用所得到的值是根据指针本身的类型而决定的，因为这一点，所以我们没办法对一个`void*`指针进行解引用，即使它指向的是一个`int`类型的变量

#### 解引用结果是左值

对一个指向非常量的指针执行解引用运算符得到的结果是一个左值，这意味着对指针解引用之后可以修改其内容：

```c
int i = 42;
int *p = &i;
*p = 30;
```



### 3. 指针运算

以`p`表示指针：

| 运算                 | 含义                                                         |
| -------------------- | ------------------------------------------------------------ |
| `p + N`              | `N`为整数，将内存按从左往右的顺序排列，该表达式的含义是将指针向右移动`N`个位置，<br />每两个位置之间的距离和指针所指的类型尺寸相同；<br />移动的距离可以是负数，可写作`p - N`的形式，表示向左移动`N`个位置 |
| `p1 - p2`            | 两个指针相减，得到的是`p2`和`p1`相差的距离，假设该距离为`N`，那么`p2 + N = p1` |
| `<`、`<=`、`>`、`>=` | 将内存按从左往右的顺序排列，指向左边地址的指针小于指向右边地址的指针 |
| `==`、`!=`           | 两指针指向相同位置它们相等                                   |

以上运算通常当指针指向数组中的某个元素时有意义：

- 指针的移动：对于非数组类型，如果移动指针，很可能导致指针指向一个未知位置，C 语言不会检查其合理性，但当我们访问这个位置时，则很有可能发生错误
- 指针相减：通常只有在数组中，我们才需要计算两个指针之间的距离
- 关系运算符：因为数组中的元素存在严格的内存顺序关系，所以在数组中使用这些运算符才是合理有效的
- 相等性运算符：可以判断两个指针是否指向同一位置，通常用于判断指针是否是某个特殊值
