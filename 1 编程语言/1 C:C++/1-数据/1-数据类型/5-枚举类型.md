## 一、创建类型

枚举类型可以看做一个有别名的整数类型，同时枚举类型也可以定义一系列枚举常量，这些常量和类型名处于同一个作用域。

使用枚举类型前需要先创建一个枚举类型，基本语法如下：

```c
enum Type_Name {
    ENUM_CONSTANT1,
    ENUM_CONSTANT2 = Integral_Value,
    ENUM_CONSTANT3,
    ...
    ENUM_CONSTANTN,
};
```

- `Type_Name`：类型名，自取。类型名可以省略。
  - 当一个枚举类型只用来提供一系列枚举常量时，或者在枚举类型定义时就用`typedef`定义新类型名了的时候，可以省略类型名
- `ENUM_CONSTANT`：枚举常量。可显式赋值，只能用整型常量表达式赋值，包括字符字面值。
  - 对于未显式赋值的枚举常量，其值为上一个枚举常量 + 1；对于第一个枚举常量，其值默认为 0
  - 枚举常量之间用逗号分隔，最后一个枚举常量末尾可以尾缀逗号

### 1. 枚举类型的底层类型

根据枚举常量的最大值决定，最小为`int`，最大为`unsigned long long`



### 2. 枚举常量的使用

枚举常量实际上就是一个整型常量，所以也可以作为整型常量使用。且一个枚举类型的变量也可以用一般的整型值初始化。

不过根据枚举类型的使用场景，更建议枚举变量只使用枚举常量，枚举常量只用在枚举变量上。



## 二、声明枚举变量/常量

```c
enum Type_Name variable;
const enum Type_Name constant = ENUM_CONSTANT;
```

将`enum Type_Name`看作一种整数类型即可。

如果一个枚举类型只使用一次，那么可以将该类型的定义和变量声明放在一起：

```c
enum Type_Name {
    ...
} variable;
```
