## 一、分支

### 1. if 语句

**语法**：

```c
if (expression)
    statement
else if (expression2)		// 可选
	statement
...						   // More else if（可选）
else					   // 可选
    statement
```

- `expression`：接受多种类型的表达式，甚至包括数组名，数组名将转换为指针，而指针将转换为整型；浮点数不进行转换，即不截段。
- `statement`：语句或代码块

> **悬垂else问题**：
>
> `else`始终和最近的`if`组合，故当有多条语句时，最好使用代码块



### 2. switch 语句

**语法**：

```c
switch (expression)
    statement
```

**常用形式**：

```c
switch (expression) {
    case const_expression1:
        statement;
        break;
    case const_expression2:
        statement;
        break;
    ...		// More Cases
    default:
        statement;
        break;
}
```

- `expression`：一个值为整型值的表达式
- `const_expression`：常量表达式，即编译时即可进行求值的表达式
- 执行流：计算`expression`的值，从与该值匹配的`case`处进入（如果没有匹配的则从`default`子句进入），一直往下执行语句（包括后续其他`case`包括`default`）直到`switch`语句结束。
- `break`主动退出：`switch`语句内的`break`将退出`switch`，而如果`switch`中存在`continue`语句，该语句的效果是重启下一次外层循环而非重启`switch`。



## 二、循环

### 1. while 语句

```c
while (expression)
    statement
```

- `expression`：接受多种类型的表达式，甚至包括数组名，数组名将转换为指针，而指针将转换为整型；浮点数不进行转换，即不截段。
- `statement`：语句或代码块



### 2. do while 语句

```c
do
    statement
while (expression);
```

- `statement`：语句或代码块
- `expression`：接受多种类型的表达式，甚至包括数组名，数组名将转换为指针，而指针将转换为整型；浮点数不进行转换，即不截段。

> 注意末尾的分号



### 3. for 语句

```c
for (expression1; expression2; expression3)
    statement
```

- `expression1`：任何表达式，通常用于初始化循环控制变量。该表达式仅在整个循环开始时执行一次。可省略
- `expression2`：接受多种类型的表达式，甚至包括数组名，数组名将转换为指针，而指针将转换为整型；浮点数不进行转换，即不截段。控制循环的进入或退出。可省略，若如此做，则`expression2`将默认为真
- `expression3`：任何表达式，通常用于更新循环控制变量。该表达式在每次循环结束时执行。可省略
- `statement`：语句或代码块



## 三、跳转

### 1. break

```c
break;
```

终止循环，仅对最内层循环有效



### 2. continue

```c
continue;
```

终止当前那次循环，立即从`while`头开始下一次循环（即先计算`expression`），对于`for`，则从`expression3`处开始



### 3. goto 语句

```c
goto label_name;
```

- 跳转到`label_name`标签所在的位置开始执行

**添加标签**：

```c
label_name:
	statement
```

- 标签可以出现在程序任何地方
