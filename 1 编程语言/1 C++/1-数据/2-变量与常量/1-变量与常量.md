## 一、声明

### 1. 标识符

- 组成：大小写字母、数字、下划线（`_`）

- 规则：

  - 不能以数字开头

  - 区分大小写

  - 不能使用关键字（C90）

    ```text
    auto		do			goto		signed		unsigned
    break		double		if			sizeof		void
    case		else		int			static		volatile
    char		enum		long		struct		while
    const		extern		register	 switch
    continue	float		return		 typedef
    default		for			short		 union
    ```
    
    - C99 新增
    
      ```text
      inline
      ```
    
    - C11 新增
    
      ```text
      _Alignas	_Bool		_Imaginary		_Thread_local
      _Alignof	_Complex	_Noreturn
      _Atomic		_Generic	_Static_assert
      ```

> C90 只允许 6 个字符的标识符，C99 开始允许使用更长的标识符，但编译器只识别前63个字符。对于外部标识符，只允许使用 31 个字符。



### 2. 基本声明

变量声明的基本形式是：

*说明符（一个或多个） 声明表达式列表*

- 说明符：包含了一些关键字，用于描述被声明的标识符的基本类型。说明符也可以用于改变标识符的缺省存储类型和作用域
- 声明表达式列表：对于简单的类型，生命表达式列表就是被声明的标识符的列表。对于更复杂的类型，声明表达式列表中的每个条目实际上是一个表达式，显式被声明的名字的可能用途

**简单类型变量声明**：

- 说明符：即被声明变量的类型
- 声明表达式列表：即标识符列表

```c
int a;
double b = 3.14;
char c, d = 'a', e;
```

> 在 C90 标准下，变量的声明应该放在块的顶部，其他语句不能在任何声明的前面；
>
> C99 开始可以把声明放在块中的任何位置



## 二、初始化

初始化即为未初始化的变量赋予初始值，对于没有显式使用`=`进行初始化的变量将进行默认初始化。

### 默认初始化

如果不对变量进行显式的初始化，那么它们将被默认初始化，对于自动存储期的变量，它们被默认初始化的结果是一个垃圾值。而对于静态存储期的变量，它们被默认初始化的结果总是 0。

如果默认初始化的对象是数组，那么对于静态存储期的数组，其所有元素初始化为 0；对于自动存储期的变量，其所有元素获得垃圾值。不允许省略数组长度的数组进行默认初始化。



## 三、常量

### 1. 一般常量

即在变量声明的类型前添加`const`关键字即可，例如：

```c
const int a = 10;
const double b = 3.14;
```

由于常量无法更改，则需要在声明时进行初始化。

> C 语言允许不初始化常量，但是对于局部变量来说，其值为垃圾值，对程序而言没有意义，故不应该这样做



### 2. 指针常量

由于指针变量包括指针本身和指针所指的对象，所以我们可以对二者都做出限定：

```c
const int *const p = NULL;
```

- 前者：限定指针所指的对象为常量，故无法通过指针修改其所指的对象
- 后者：限定指针本身为常量，故无法修改指针所指的对象



## 四、变量及常量的属性

### 1. 作用域

#### 块作用域

一个代码块就是一个作用域，称为**块作用域**。

函数定义时函数形参的作用域为函数体最外层的作用域，故函数内无法声明和形参同名的标识符。



#### 文件作用域

在任何块或形参列表外声明的任何标识符的作用域，在声明点开始，翻译单元尾结束。



#### 函数作用域

声明于函数内部的标签（且只有标签），在该函数中的所有位置（所有嵌套块中，其自身声明前后）都在作用域内。注意：任何语句前的冒号字符前的标识符，若不用于其他用途，则隐式声明一个标号。

注意函数中的变量应该属于块作用域而非函数作用域。



#### 原型作用域

非函数定义的函数声明的形参列表中引入的名称的作用域，在函数声明器的结尾结束。



#### 嵌套作用域

作用域可以嵌套，内层作用域创建的和外层作用域同名的变量将覆盖外层作用域的标识符。



### 2. 存储期和链接

#### 链接属性

- 外部链接：可在其他文件声明并使用同一个变量实体
- 内部链接：在同一个文件中表示同一个实体，不能用于其他文件
- 无链接：仅在对应作用域有效

> 对于有外部链接的变量，如果要在其他文件中使用同一个变量，则需要先声明，且在声明前添加`extern`关键字，且不允许重新初始化



#### 存储期

- 自动存储期：进入变量所处块时分配内存，退出该块时回收内存
- 静态存储期：存在于整个程序的执行过程



#### 定义域对应的存储期和链接属性

- 块作用域变量默认**无链接**并拥有**自动存储期**
- 文件作用域变量默认拥有**外部链接**和**静态存储期**



#### 存储类说明符

- `auto`：自动存储期与无链接。说明符只允许用于声明于块作用域的对象（除了函数形参列表）。它指示自动存储期与无链接，也是这种声明的默认属性。

- `register`：自动存储期与无链接。说明符只允许用于声明于块作用域的对象，包括函数形参列表。它指示自动存储期与无链接（即这种声明的默认属性），但另外提示优化器，若可能则将此对象的值存储于 CPU 寄存器中。无论此优化是否发生，声明为 register 的对象不能用作取址运算符（`&`）的参数，而且 register 数组不能转换为指针。

- `static`：静态存储期与内部链接。对于文件作用域的变量，`static`的作用就是将该变量修改为内部链接。对于块作用域变量，`static`的作用是将其修改为静态存储期，但并无内部链接属性，即不意味着能在该变量所处作用域外访问该变量。不能使用在函数形参上。

- `extern`：静态存储期与外部链接。用于再声明一个定义在他处的变量。若在`extern`声明处其前置声明可见并且具有内部或外部链接，那么此处和前处具有相同的链接属性并指向同一个实体。如果`extern`声明处其前置声明不可见或在其前面有一个可见的块作用域的同名变量（无链接属性），那么此处的`extern`声明将具有外部链接属性，并在构成一整个程序的整组编译单元和库中和所有同名的并具有相同链接属性的变量指向同一实体。也就是说即使在`extern`声明处前面有一个可见的块作用域的同名变量，使用`extern`声明的这个变量也并不是和它指向同一个实体的。

  使用头文件来管理外部链接的变量可以提高封装性，例如：
  
  ```c
  // file.h
  extern int globalVal;
  
  // file1.c
  #include "file.h"
  int globalVal = 10;
  
  // file2.c
  #include "file.h"
  int main(void) {
      printf("%d\n", globalVal);
  }
  ```
