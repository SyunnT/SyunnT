## 一、数组类型

### 1. 一维数组

用于保存一组相同类型的数据元素，这些元素在内存中顺序排列



### 2. 二维数组

即数组元素也是数组的数组，所有数据元素仍然在内存中线性排列，不过在处理这类数组的时候按照矩阵的逻辑结构进行处理



### 3. 字符串

字符串即字符数组，一个完整的字符串必须由`'\0'`结尾，即空字符。和数组一样，多数时候会转换为一个字符指针。

**字符串字面值**：以双引号括起来的由字符字面值组成的字面值，如：`"Hello World!"`，该字符串包含 13 个字符，包括末尾的`'\0'`。相邻的字符串字面值会被自动连接为一个字符串

字面值后缀及对应类型：

- 无后缀：字符串中元素类型为`char`类型，注意此处和字符不同，无后缀的字符字面值为`int`类型。字面值编码转换为`fexec-charset`（以 GCC 为例，也可以是其他编译器的等效设定）设定的编码

  > GCC：默认为`utf-8`
  >
  > MSVC：中文环境下的 Windows 默认为 gb2312

- `L`后缀：元素类型为`wchar_t`类型。字面值编码转换为 Unicode，具体编码根据系统和编译器而定

- `u`：元素类型为`char16_t`类型。字面值编码转换为 UTF-16

- `U`：元素类型为`char32_t`类型。字面值编码转换为 UTF-32

- `u8`：元素类型仍为`char`类型。字面值编码转换为 UTF-8

> 以上转换正确进行的前提是编译器正确识别源文件的编码，例如源文件编码为`gb2312`时，对于 GCC 编译器来说，需要将`finput-charset`选项设定为`gb2312`



## 二、操作

### 1. 声明与初始化

基本声明形式如下：

```c
ElemType arr_name[ARR_SIZE];
```

初始化采用花括号的列表形式，如：

```c
int vector[5] = {10, 20, 30, 40, 50};
```

> 数组的初始值不能是其他数组变量，即数组不能拷贝



#### 花括号列表初始化

使用花括号中包含多个表达式（可以是字面值或变量）的方式对数组进行初始化，多个表达式之间用逗号分隔，如：

```c
int vector[5] = {10, 20, 30, 40, 50};
```

- 不完整初始化：当花括号列表中的初始值少于数组元素数量时，后续无初始值的元素初始化为 0

- 省略数组长度：数组长度将根据花括号列表中的初始值个数判断

  > 如果省略数组长度，则必须有花括号列表，如果花括号列表为空，则为空初始化，对于省略数组长度的数组来说，数组将不包含有任何元素

如果显式给出的数组长度无法保存字面值所有元素将导致错误（字符串字面值初始值除外），部分编译器只会给出警告，其实际行为是将字面值依次保存在数组中，数组中所有元素都得到初始值后就不再保存元素，其余数据将被丢弃。



#### 字符数组初始化

字符数组可以使用花括号列表进行初始化，不过如果想要一个数组用来保存字符串，用得最多的还是如下的形式：

```c
char str[] = "Hello World!";
```

- 此处字符串字面值实际上并非字符串字面值，而应该看作一个花括号列表，其中的元素由字符串中每个元素构成，包括末尾的空字符。字符串字面值初始值也可以放在花括号中：

  ```c
  char str[] = {"Hello World!"};
  ```

> 其余规则遵循花括号列表初始化的规则



#### 空初始化（C23 起支持）

用空的花括号列表初始化，如：

```c
int arr[5] = {};
```

空初始化将把每个元素初始化为 0，如果元素是数组，则进行递归空初始化

如果使用空初始化的同时省略数组长度，那么数组将不包含任何元素。



#### 指定初始化器（C99 起支持）

初始化列表中的值将依次给数组每个元素进行初始化，但也可以使用指定初始化器来给特定的元素进行初始化：

```c
int arr[5] = {[4] = 5, [0] = 1, 2, 3, 4};	// arr 被初始化为 {1, 2, 3, 4, 5}
```

如果使用了指定初始化器，那么该值就会用于初始化指定初始化器对应下标的元素，如果没有使用指定初始化器，该值就用于初始化上一个被初始化的元素的后一个元素

**省略数组长度时**：数组长度由指定初始化器的下标和列表中的元素数量共同决定

**反复初始化**：如果因为使用指定初始化器导致某个元素被初始化了两次，那么该元素的值被后来的初始化值覆盖（最好不要反复初始化）。



#### 多维数组

多维数组即元素为数组的数组，以二维数组为例，声明方法如下：

```c
int arr[N][M];
```

`arr`首先和`[N]`结合，表示它有`N`个元素，再和`[M]`结合，表示这`N`个元素都是拥有`M`个元素的数组。

为方便后续表述，将其描述为`N`行`M`列的二维数组

**单层列表初始化**：

```c
int arr[3][3] = {1, 2, 3, 4};
```

- 列表中的值按顺序依次给数组中每个元素赋值，第一行的被初始化为`{1, 2, 3}`，第二行第一列的元素被初始化为`4`，其余所有元素被初始化为 0

**单层列表指定初始化器**：

可以在任意位置使用一个下标表示定位到某一行开始初始化：

```c
int arr[3][3] = {1, 2, [2] = 3, 4};		// 初始化结果为第一行为 {1, 2, 0}, 第三行为 {3, 4, 0}, 第二行全为 0
```

- 该用法可读性较低，故应该少用

****

也可以在任意位置使用两个下标表示定位到某一个具体元素开始初始化：

```c
int arr[3][3] = {1, 2, [1][1] = 3, 4};	// 初始化结果为第一行为 {1, 2, 0}, 第二行为 {0, 3, 4}, 第三行全为 0
```

**嵌套列表初始化**：

```c
int arr[3][3] = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};
```

- 外层列表中的每一个内层列表都初始化一整行的数据，无论该列表中的元素是少还是多。如果少了，则该行后续的元素用 0 初始化；如果多了，则丢弃（通常不允许多）

**嵌套列表指定初始化器**：

在每一个内层列表内，只能用一个下标表示该行中某个位置，如：

```c
int arr[3][3] = {
    {},
    {[1] = 5}
};		// 仅将第二行第二个元素初始化为 5，其余初始化为 0
```

****

在每一个内层列表前，可以用一个下标表示该列表用于初始化某一行：

```c
int arr[3][3] = {
    [1] = {[1] = 5};
};		// 仅将第二行第二个元素初始化为 5，其余初始化为 0
```

****

在每一个内层列表前，也可以用两个下标表示该列表用于初始化某一行某一列开始的一整行元素：

```c
int arr[3][3] = {
    [1][1] = {5};
};		// 仅将第二行第二个元素初始化为 5，其余初始化为 0
```

在用两个下标指定的位置后的内层列表中不允许再使用指定初始化器

**省略数组长度**：

由于多维数组是元素为数组的数组，作为元素类型的数组是不允许省略的，所以除了第一个下标运算符中的数字可以省略外，其余下标运算符中的数字都不能省略：

```c
int arr[][3] = {
    {1, 2, 3},
    {4, 5},
    {7, 8, 9}
};

// 或

int arr[][3] = {1, 2, 3, 4, 5, 0, 7, 8, 9};
```



### 2. 下标引用

数组元素可以通过数组名和下标来访问：

```c
char arr[] = "Hallo World!";

arr[1] = 'e';	// 将第二个字符 a 修改为 e
```

- 下标从 0 开始，所以 1 是第二个元素，最多到`N-1`（`N`为数组长度）
- C 语言不会在编译时对下标进行检查，如果下标越界，编译器不会报错
- 下标运算符允许的操作数为带符号整数，所以可以为负，但具体行为需要程序员自己负责

#### 指针访问元素

数组名可以在多数地方转换为指针，如果我们声明一个指向数组元素类型的指针并用数组名初始化这个指针，那么指针就指向数组的第一个元素，此时下面两种使用方法是等价的：

```c
char *str = arr;

arr[1] = 'e';
*(str + 1) = 'e';
```

****

由于`str`这个指针本身指向数组，在我们能确保这个指针向前或向后移动`N`个位置仍然指向有效位置的情况下，可以直接将其当做数组使用：

```c
str[1] = 'e';
```

实际上指针在任何时候都可以写出下标访问表达式，编译器并不检查，但如果其指向无效位置，此时对该指针的访问或修改将可能导致无法预计的结果，所以不要这样使用。

****

一种比较特殊的用法是，指针还可以指向数组中某个元素的位置，例如：

```c
char *str3 = &arr[2];
```

此时`str3`指向数组中第三个元素的位置，即`str3[0]`将得到该元素的值，在这种情况下，如果我们将`str3`当做一个数组看待，那么它的元素的有效范围就变成了`-2 ~ N - 3` ，对这个指针使用任何超过这个范围的下标访问元素将同样导致上述无法预计的结果。



### 3. 取址

对数组取址是一个容易被混淆的地方，因为数组名本身会自动转换为指向第一个元素的指针，所以可能会误以为`arr`和`&arr`是同一个含义。

实际上，当数组名发生转换时，其对应的完整表达式应该是：

```c
&arr[0];
```

而`&arr`则是对整个数组取址，对应的指针类型应该是：

```c
ElemType (*parr)[N];
parr = &arr;
```

在这个声明中，数组类型的要素不能省略，包括元素类型`ElemType`和数组长度`N`

需要注意的是指向数组的指针不能直接当成数组一样使用，必须先解引用才能和数组一样使用：

```c
parr[1];		// 错误
*parr[1];		// 正确：此处有些违反解引用运算符的优先级，解引用运算符会优先和 parr 结合
(*parr)[1];		// 正确：严谨起见应该用这种形式
```



### 4. 数组类型函数形参

#### 指向元素的指针

一个接受数组参数的函数通常并非接受一个数组，而是接受其转换类型，即一个指向数组元素类型的指针。传入这类数组参数时需要更多的形参来描述这个数组的边界，否则将无法处理数组，只能当做一个指针处理：

```c
void fun1(int size, int *arr);		// 直接传入长度参数
void fun2(int *end, int arr[]);		// 传入一个指向数组末尾元素或末尾元素后一个位置的指针用于标识结束点
					// arr[] 形式的形参和 *arr 形式的形参是等价的，并不认为传入的是一个数组，仅用于提高可读性
					// arr[] 的下标运算符中可以填入任何整数，但没有意义
void fun3(char *str);				// 传入的如果是字符串，可以不传入其他标识，可以根据字符串末尾的空字符判断数组的结束
```

#### 指向数组的指针

我们也可以传入一个指向数组的指针而非指向数组元素的指针：

```c
void fun(int (*parr)[10]);		// 调用这个函数时应该传入 &arr，而不是 arr，因为 arr 是 &arr[0]
```

此时就不需要其他标识数组范围的参数了，在这个函数声明时起，该函数就默认所有传入的函数为 10 个元素。

作为用户，最好也应该传入 10 个元素的该元素类型的数组。如果传入更小或更大的数组，将会导致指针转换错误，部分编译器只反馈警告。如果因为强制转换或编译器等原因能够编译通过，也应该传入大于等于 10 个元素的数组，在这种情况下，第 10 个元素之后的其余元素不会被处理；而如果是传入的小于 10 个元素的数组，那么很很可能会导致下标越界的问题。



### 5. 不允许直接拷贝

数组并不允许直接拷贝，即使它们的元素类型和大小都相同。



## 三、变长数组（VLA）

> C99 起支持，C11 起变为可选

在 C99 之前，声明数组时，数组的大小只能是**整型常量表达式且必须大于 0** 或者根据初始值列表自动获得数组大小，整型常量表达式即使用整型常量构成的表达式，能在编译阶段就计算出大小的表达式。`sizeof`表达式被视为整型常量，而`const`值不是。

从 C99 开始，C 语言开始支持变长数组。允许用变量来表示数组的维度，但有一些限制，如变长数组必须是自动存储类型，也就是说这种类型的数组只能在块内声明或作为函数形参声明，并且不能用`static`或`extern`存储类别说明符。并且不能在声明的同时初始化它们。

如果变长数组作为函数形参声明，对于一维数组来说没有什么使用上的影响，依然传入一个指针以及一个指示其维度的数据。不过，也可以像这样写：

```c
int fun(int size, int arr[size]);
// or
int fun(int size, int arr[*]);
```

这种函数声明方式明示了传入的数组是一个变长数组，在这种情况下，数组的大小参数应该先传入，然后声明数组形参的时候，需要使用这个参数作为维度。也可以省略，但需要用星号代替。

对于二维数组来说，如果传入的是非变长数组，那么这个数组指针的第二个维度是必须确定的，对于第二个维度不同的数组来说，就不能用同一个函数进行处理，而想让函数处理一个变长二维数组，可以像这样：

```c
int fun2(int row, int col, int arr[row][col]);
// or
int fun2(int row, int col, int arr[*][*]);
```

这种方式仍然表示传入的是变长数组，所以需要先声明两个维度数据，然后声明数组形参，且形参的两个维度需要用前面声明的参数或用星号代替。



## 四、复合字面量（C99 起）

复合字面量的语法格式为：`(arr_type){value_list}`，例如：

```c
(int [2]){10, 20}
```

类型中的数组大小可以省略，此时会根据列表中值的个数确定其大小。

复合字面量的类型是一个数组类型，它的具体类型即括号中声明的类型。作为数组，它也可以转换为一个指向首元素的指针，所以可以将它赋值给一个指向元素类型的指针以及作为函数参数传递。

复合字面量具有块作用域，离开块后就无法保证其是否还存在。同时由于复合字面量实际上是一个数组，所以即使它跟数组的初始值列表长得再像也不能作为数组的初始值，因为数组不允许拷贝，而且也没必要，毕竟如果作为数组的初始值，那么前面的类型部分就完全是多余的。
