## 一、预定义符号

以下是一些预处理器定义的符号，其值是字符串常量或十进制数字常量，可以直接在程序中使用：

| 符号       | 含义            | 示例值                                        |
| ---------- | --------------- | --------------------------------------------- |
| `__FILE__` | `"name.c"`      | 进行编译的源文件名                            |
| `__LINE__` | `25`            | 文件当前行的行号                              |
| `__DATE__` | `"Jan 31 1997"` | 文件被编译的日期                              |
| `__TIME__` | `"18:04:30"`    | 文件被编译的时间                              |
| `__STDC__` | `1`             | 如果编译器遵循 ANSI C，其值就为 1，否则未定义 |



## 二、#define

`#define`的正式语法为：

```c
#define name stuff
```

在这条指令之后，每当出现`name`就会被替换为`stuff`

****

当`stuff`特别长时，可以使用反斜杠加回车分成多行，如：

```c
#define DEBUG_PRINT printf("File %s line %d:" \
						" x=%d, y=%d, z=%d",\
						__FILE__, __LINE__,\
						x, y, z)
```

****

### 1. 宏

`#define`允许把参数替换到文本中，这种实现通常称为宏或定义宏，其声明方式如下：

```c
#define name(parameter-list) stuff
```

- `parameter-list`：一个由逗号分隔的符号列表，它们可能出现在`stuff`中，左括号必须和`name`紧邻，否则参数列表会被解释为`stuff`的一部分

****

例如：

```c
#define SQUARE(x) x * x		// 定义宏

SQUARE(5)				   // 使用宏，计算 5 的平方
```

> **注意**：宏的作用是将参数形式完全复制到`stuff`中，而非先计算再传入的类似于函数调用的过程。
>
> 所以，上述示例中，如果调用形式如下：`SQUARE(5 + 1)`，并不会打印 36，而是 11，是因为，这个宏调用将会扩展为：
>
> ```c
> 5 + 1 * 5 + 1
> ```
>
> 更好的宏定义方式是在每个参数都加上括号：
>
> ```c
> #define SQUARE(x)	(x) * (x)
> ```
>
> ****
>
> 但即使加上括号，也还是可能会出现问题，例如：
>
> ```c
> #define DOUBLE(x) (x) + (x)
> 
> 10 * DOUBLE(5);
> ```
>
> 由于宏实际上是文本替换而非函数调用，所以上述调用被扩展为：
>
> ```c
> 10 * (5) + (5)
> ```
>
> 最终结果为 55，而非期待的 100。
>
> 所以更保险的做法是在整个表达式外侧再加上一个括号：
>
> ```c
> #define DOUBLE(x) ((x) + (x))
> ```



### 2. #define 替换

在程序中扩展`#define`定义的符号和宏时，需要涉及以下几个步骤：

1. 在调用宏时，首先对参数进行检查，如果参数中包含了任何由`#define`定义的符号，则它们首先被替换
2. 替换文本随后被插入到程序中原来文本的位置。对于宏，参数名被它们的值所替代
3. 最后，再次对结果文本进行扫描，看看它是否包含了任何由`#define`定义的符号，如果是，就重复上述处理过程

这样，**宏参数和`#define`定义可以包含其他`#define`定义的符号。但是，宏不可以出现递归**

****

字符串中的文本不会被检查，如果想把`#define`定义的符号或者宏参数插入到字符串中，则需要使用字符串的特性，即两个邻近字符串会被连接在一起构成一个字符串。

****

宏参数可以在宏定义中被转换为字符串，当输入实参时，会将整个实参表达式转换为字符串连接在其中，如：

```c
#define PRINT(FORMAT, VALUE) \
	    printf("The value of " #VALUE " is " FORMAT "\n", VALUE)
```

当我们像下面这样调用时：

```c
PRINT("%d", x + 3);
```

会被扩展为：

```c
printf("The value of " "x + 3" " is " "%d" "\n", x + 3);
```

然后多个相邻字符串连接成一整个字符串，假设`x`的值是`22`最终的打印结果就是：

```
The value of x + 3 is 25
```

****

可以使用`##`符号将符号和宏参数连接在一起构成一个新的符号，例如：

```c
#define ADD_TO_SUM(sum_number, value) \
	    sum ## sum_number += value
```

在这条宏定义中，`sum`只是一个单纯的符号，没有可用于替代的文本，所以保持`sum`不变，而`sum_number`则是一个宏参数，它会替换为宏参数的完整表达式形式，例如，如果像这样调用：

```c
ADD_TO_SUM(5, 25);
```

就会扩展为：

```c
sum5 += 25;
```

`sum_number`扩展为`5`并通过`##`符号和`sum`连接在一起。

需要注意的是，这种连接必须产生一个合法的标识符，否则其结果就是未定义的。

另外仍需注意宏参数整个表达式是直接复制到宏中进行扩展的，例如：

```c
ADD_TO_SUM(1 + 2, 25);
```

将会扩展为：

```
sum1 + 2 += 25;
```

这是一个错误的表达式，所以会编译出错



### 3. 带副作用的宏参数

部分宏参数带有副作用，例如`x++`，`getchar()`等，如果在调用宏时使用这种参数，那么就可能导致不可预料的结果，例如：

```c
#define MAX(a, b)	((a) > (b) ? (a) : (b))
```

当如下调用时：

```c
int z = MAX(x++, y++);
```

它将被扩展为：

```c
((x++) > (y++) ? (x++) : (y++));
```



## 三、#undef

`#undef`用于移除一个宏定义：

```c
#undef NAME
```

如果一个现存的名字需要被重新定义，那么首先必须用`#undef`移除它的旧定义



## 四、编译器命令行定义符号

可以在执行编译命令时定义符号，以 GCC 为例，可以像下面这样执行 gcc 命令：

```bash
gcc -DARRAY_SIZE=100 prog.c
```

我们也可以只提供符号，不提供值，那么该符号的值将会为 1：

```bash
gcc -DARRAY_SIZE proc.c
```



## 五、条件编译

### 1. #if、#elif、#else、#endif

和 C 语言的`if`语句类似：

```c
#if constant-expression
	statements;
#endif
```

- `constant-expression`：是一个常量表达式，即一个能在编译期间就得到值的表达式。若为 0 则为`false`，否则为`true`

- 和`if`语句类似，`#if`也有对应的可选的`#elif`和`#else`，如：

  ```c
  #if constant-expression1
  	statements;
  #elif constant-expression2
  	statements;
  ...
  #else
      statements;
  #endif
  ```

- 需要注意最后的`#endif`不能缺少



### 2. #ifdef、#ifndef

如果只想判断一个符号有没有被定义，例如通常用于 Debug 的`DEBUG`，可以使用`#ifdef`和`#ifndef`

```c
#ifdef SYMBOL_A		// 当 SYMBOL_A 被定义时进入
	statements;

#ifndef SYMBOL_B	// 当 SYMBOL_B 未被定义时进入
	statements;
```

`#ifdef`、`#ifndef`和下面的`#if`是等价的：

```c
#if defined(SYMBOL_A)

#if !defined(SYMBOL_B)
```



## 六、文件包含

`#include`有两种文件包含形式：

```c
#include <stdio.h>
#include "self.h"
```

- 尖括号形式的头文件会从系统的标准位置和编译时指定的位置中去查找对应的头文件
- 双引号形式的头文件会优先从包含该头文件的源文件所在目录查找，如果失败，再按照和尖括号相同的方式去查找



## 七、其他指令

### 1. #error

用于生成错误信息：

```c
#error text of error message
```



### 2. #line

用于通知预处理器下一行输入的行号，且可添加可选部分，预处理器将该部分作为当前文件的名字：

```c
#line number "string"
```

需要注意，这条指令会修改预定义符号中`__LINE__`符号的值以及`__FILE__`符号（如果添加了可选部分，例如上面的`"string"`的话）的值



### 3. #progma

是由编译器提供的特殊指令，因编译器而异。预处理器会忽略它不认识的`#progma`指令



### 4. 无效指令

只有一个`#`而后面没有其他内容的一行指令，它没有任何作用。
