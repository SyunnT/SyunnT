## Python

在 Windows 上，一个完整的 Python 程序的安装目录应该包含以下内容：

- root
  - python.exe
  - Scripts
    - pip.exe
    - [其他通过pip安装的包]

在其他平台，Python 和 pip 通常是两个需要独立安装的程序。

通过对应的包管理器来管理版本，或安装对应版本的离线包进行管理。

**环境变量**：确保 python 和 pip 可访问即可



## pipx

- 用途：用于安装不寄宿于 pip 列表的 pip 包
- 安装方式：
  - 通过 pip 安装：在 Windows 下安装在对应的 pip 目录下，包括其他依赖程序
  - 通过包管理器：依赖由对应的包管理器管理，程序与 pip 分离，但 pip 仍能通过 list 获取对应程序的列表
- **环境变量**：确保 pipx 和其安装的程序可访问即可
