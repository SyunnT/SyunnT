## 一、数据

### 1. 变量

- 无需类型，直接写变量名即可：

  ```python
  message = "Hello World!"
  ```
  
- 创建变量必须给初始值进行定义

- 同时给多个变量赋值（变量与值的个数要相同）：

  ```python
  x, y, z = 1, 2.4, "Hello"
  ```
  
- Python 没有常量



### 2. 字符串

- 可以使用单引号或双引号引起字符串，在字面值内可以直接使用另一种引号而无需转义符

- 字符串中可以使用变量，方法是在字面值前添加`f`，在变量周围添加花括号：

  ```python
  first_name = "ada"
  last_name = "lovelace"
  full_name = f"{first_name} {last_name}"
  ```

  

### 3. 数

- 运算：`+`、`-`、`*`、`/`（浮点数除法）、`**`（乘方）

- 数的表示：数中间可以添加下划线，提高易读性

  ```python
  universe_age = 14_000_000_000
  ```

  

### 4. 列表

- 列表是对象，直接将列表赋值给另一个列表它们将指向同一个列表

- 列表使用方括号存储数据：`['hello', 1, 2.4]`。列表中的数据可以是不同类型的

- 访问时通过列表名和索引访问，索引从 0 开始，正数表示从头开始数，负数表示从尾部开始数，索引为 -1 时返回最后一个列表元素，-2 时返回倒数第二个，以此类推。索引越界时会报错

- 可以使用列表推导式创建列表，如：

  ```python
  squares = [value**2 for value in range(1, 11)]
  ```

  - `value**2`是每一次要添加的值，后面是一个`for`循环头
  
- 列表切片：使用方法如下

  ```python
  varlist = list(range(0, 10))
  slice_list = list[0:5]	# 切片
  ```
  
  - 切片也是一个列表，但不同于原列表，是一个新的列表对象
  - 切片的元素范围为`[start, stop)`，`start`和`stop`都可以省略且可以同时省略，如果省略`start`，则其含义为从头开始，如果省略`stop`则其含义为直到末尾。`start`应该小于`stop`，否则切片不会包含值。当索引越界时，将用列表长度值替代改值，不会访问到更后续的内存（向上越界时，为列表长度值，向下越界时，为负的列表长度值



### 5. 元组

- 元组使用圆括号存储数据：`(200, "list", 30.5, True)`。类型可以不同

  > 实际上，元组是由逗号标识的，圆括号只是让元组看起来更整洁、更清晰，但即使没有圆括号也不影响它是一个元组。所以如果要定义一个只包含一个元素的元组，必须在这个元素后面加上逗号：
  >
  > ```python
  > my_t = (3,)
  > ```

- 元组中元素的值是不可变的

- 元组也是对象

- 元素可通过索引访问



## 二、语句

### 1. del

- `del`删除列表元素：

  ```python
  del var_list[0];
  ```

  

### 2. for

```python
for elem in var_list:
    do_something();
```

- `var_list`的类型可以是**列表**、**`range`**、元组

- `elem`的类型将根据每次迭代的实际元素类型而变化
