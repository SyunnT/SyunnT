函数模板可以被另一个模板或一个普通非模板函数重载。和之前一样，名字相同的函数必须具有不同数量或类型的参数

## 一、函数匹配规则的影响

当涉及函数模板，则函数匹配规则会在以下几方面受到影响：

- 对于一个调用，其候选函数包括所有模板实参推断成功的函数模板实例
- 候选的函数模板总是可行的，因为模板实参推断会排除任何不可行的模板
- 与往常一样，可行函数按类型转换优劣来排序。用于函数模板调用的类型转换有限
- 与往常一样，如果恰有一个函数提供比任何其他函数都更好的匹配，则选择此函数。但是如果有多个函数提供同样好的匹配，则：
  - 如果同样好的函数中只有一个是非模板函数，则选择此函数
  - 如果同样好的函数中没有非模板函数，而有多个函数模板，且其中一个模板比其他模板更特例化，则选择此模板
  - 否则，此调用有歧义



## 二、示例

### 示例1

```cpp
template <typename T>
string debug_rep(const T &t);

template <typename T>
string debug_rep(T *p);
```

考虑以下调用：

```cpp
string s("hi");
debug_rep(s);		// 调用1
debug_rep(&s);		// 调用2
```

- 对于调用1，只有第一个版本的`debug_rep`是可行的。非指针实参无法转换为一个期望指针类型参数

- 对于调用2，两个函数都可行

  - `debug_rep(const string*&)`；
  - `debug_rep(string*)`；

  但第一个版本会进行普通指针到`const`指针的转换，故劣于第二个版本



### 示例2：更特例化的版本

考虑以下调用：

```cpp
const string *sp = &s;
debug_rep(sp);
```

此例中，两个模板都可行且都是精确匹配：

- `debug_rep(const string*&)`
- `debug_rep(const string*)`

但根据规则，`debug_rep(T*)`是**更特例化**的版本，所以调用第二个模板。

> 对于`debug_rep(cosnt T&)`本质上可以用于任何类型，包括指针类型，它比`debug_rep(T*)`更通用，后者只能用于指针类型



### 示例3：优先选择非模板函数

在之前示例上新增一个重载函数：

```cpp
string debug_rep(const string &s);
```

考虑以下调用：

```cpp
string s("hi");
debug_rep(s);
```

可以匹配到同样好的两个可行函数：

- `debug_rep<string>(const string&)`
- `debug_rep(const string &)`

同样，根据规则，优先选择非模板函数，即调用第二个可行函数。实际上此规则仍然遵循调用更特例化的版本这一规则。



### 示例4：类型转换

考虑以下调用：

```cpp
debug_rep("hi world!");
```

对于此调用，上述所有版本都是可行的：

- `debug_rep(const T&)`：`T`绑定到`char[10]`，精确匹配
- `debug_rep(T*)`：`T`被绑定到`const char`，要求数组到指针的转换，但仍为精确匹配
- `debug_rep(const string &)`：要求从`const char*`到`string`的类型转换，三者中较劣匹配

能做到精确匹配的就是前两个版本，然后根据更特例化更优的原则，会选择第二个版本。
