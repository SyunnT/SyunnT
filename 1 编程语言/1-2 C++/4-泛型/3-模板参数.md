### 1. 模板参数与作用域

- 一个模板参数名的可用范围是在其声明之后，至模板声明或定义结束之前。
- 模板参数会隐藏外层作用域中声明的相同名字。
- 在模板内不能重用模板参数名，即便是变量名和模板类型参数同名也不行，反之同理



### 2. 模板声明

- 模板声明必须包含模板参数：

  ```cpp
  template<typename T> int compare(const T&, const T&);
  template<typename T> class Blob;
  ```

- 和函数参数相同，如果声明和定义分开，那么声明中的模板参数的名字不必与定义相同，但无论是声明还是定义，相对关系不能变，例如，上面的函数模板两个形参的类型应该和模板形参类型相同



### 3. 访问模板形参中的类型成员

- 访问一个特定类的成员时，编译器可以知道这个成员是不是类型成员，因为被访问的类是确定的。而如果要访问模板形参中提供的某个暂未传入类型实参的类型形参的成员，C++会假定通过作用域运算符访问的名字不是类型，例如：

  ```cpp
  template<typename T>
  class Test
  {
  public:
      using size_type = T::size_type;		// 此时会出错，T::size_type 不会被当做一个类型处理
  };
  ```

- 使用`typename`告诉编译器这是个类型成员就可以解决（不能使用`class`关键字）：

  ```cpp
  template<typename T>
  class Test
  {
  public:
      using size_type = typename T::size_type;
  };
  ```



### 4. 默认模板实参

#### 添加方法

和给函数形参添加默认实参类似：

- 函数模板默认实参：

  ```cpp
  template<typename T, typename F = less<T>>
  int compare(const T& v1, const T& v2, F f = F())
  {
      if (f(v1, v2)) return -1;
      if (f(v2, v1)) return 1;
      return 0;
  }
  ```

- 类模板默认实参

  ```cpp
  template<typename T = int> 
  class Numbers 
  {
      // ...
  };
  ```

- 和函数形参的默认实参相同，一个模板形参的默认实参在添加时，其右侧的所有参数都必须有默认实参

#### 使用方法

- 函数模板默认实参：仍然可以隐式推导

- 类模板默认实参：仍然不能隐式推导，如果所有模板形参都有默认实参且调用时全部使用默认实参时，也需要显式添加一个尖括号来实例化：

  ```cpp
  Numbers<> n;
  ```
