当模板被使用时才会进行实例化，也就是说相同的实例可能出现在多个对象文件中。

我们可以通过**显式实例化**来避免这种开销。

### 1. 基本形式

```cpp
extern template declaration;		// 实例化声明
template declaration;			    // 实例化定义
```

示例：

```cpp
extern template class Blob<string>;		// 声明
template class Blob<string>;		    // 定义
```

```cpp
extern template int compare(const int&, const int&);	// 声明
template int compare(const int&, const int&);			// 定义
```

### 2. 解析

- 当编译器遇到含`extern`的声明语句时，并不会在当前文件中生成实例化代码。可以将其放进每一个会用到此实例的文件中，也可以将其放进头文件中，令每个使用此实例的文件包含其即可。
- 当使用`extern`声明的时候，会查找实际的定义，编译时必须和这个定义一起编译，所以通常将定义单独放进一个源文件中或编译为库文件。

### 3. 显式实例化会实例化所有成员

如果不是显式实例化，那么会根据实际用到的函数决定去实例化哪些成员；而对于显示实例化，由于在定义时没有任何用例，所以只能假设所有函数都会被用到，故所有成员都会被实例化。
