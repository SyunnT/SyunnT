## 一、参数包

- 一个可变参数模板就是一个接受可变数目参数的的模板函数或模板类，可变数目的参数被称为**参数包**

- **模板参数包**：表示零个或多个模板参数。通过`typename...`或`class...`表示接下来的参数表示零个或多个类型的列表

- **函数参数包**：表示零个或多个函数参数。一个类型名后面跟一个省略号表示零个或多个给定类型的非类型参数的列表。在函数参数列表中，如果一个参数的类型是一个模板参数包，那么这个参数也是一个函数参数包。例如：

  ```cpp
  template<typename T, typename... Args>
  void foo(const T &t, const Args& ... rest);
  ```

和之前一样，编译器从函数的实参推断模板参数类型。对于一个可变参数模板，编译器还会推断包中参数的数目。

****

当我们需要知道包中有多少元素时，可以使用`sizeof...`运算符，例如：

```cpp
sizeof...(Args);
sizeof...(rest);
```

和`sizeof`运算符相同，`sizeof...`运算符也返回一个常量表达式，且不会对其实参求值。



## 二、可变参数函数

可变参数函数通常是递归的。第一步调用处理包中的第一个实参，然后用剩余实参调用自身。为了终止递归，通常还需要定义一个非可变参数的版本。

示例：

```cpp
template<typename T>
ostream& print(ostream& os, const T &t)
{
    return os << t;
}

template<typename T, typename... Args>
ostream& print(ostream& os, const T &t, const Args&... rest)
{
    os << t << ", ";
    return print(os, rest...);		// 递归调用
}
```

- 如果只传入两个参数，那么选择更特例化的前者，即用于终止递归的函数
- 如果传入 3 个及以上的参数，第二个版本中的第二个参数就比较巧妙，有了这个参数，每一次调用`print(os, rest...)`就可以实际获取`rest...`中的第一个参数，并在下一次调用时将这个参数排除在外。



## 三、包扩展

包扩展实际上就是使用参数包的过程，实际上前面的例子已经用过了：

- 简单包扩展

  ```cpp
  template<typename T, typename... Args>							// 创建模板参数包
  ostream& print(ostream& os, const T &t, const Args&... rest)	  // 扩展模板参数包为一个类型的列表；创建函数参数包
  {
      os << t << ", ";
      return print(os, rest...);									// 扩展函数参数包为一个参数的列表
  }
  ```

  - `const Args& ...`、`rest...`这样的形式就是在进行包扩展

- 复杂包扩展

  ```cpp
  template<typename T, typename... Args>
  ostream& &errorMsg(ostream& os, const Args&... rest)		// 简单包扩展
  {
      return print(os, debug_rep(rest)...);				   // 复杂包扩展
  }
  ```

  如果对其形式进行描述的话，可以描述为：将一个函数参数包名作为函数的参数，然后在这条调用表达式后添加`...`省略符，表示对函数参数包中的每一个参数依次调用该函数。

  假设`rest`进行简单包扩展（即`rest...`）得到一个参数列表如下：`v1, v2, v3`。那么`debug_rep(rest)...`就得到下面的调用列表：`debug_rep(v1), debug_rep(v2), debug_rep(v3)`

  需要注意的是不能写成`debug_rep(rest...)`，这表示先将参数包进行扩展，然后再用这堆参数调用`debug_rep`，但`debug_rep`没有对应的版本。

  另外，这样的包扩展形式不仅适用于函数调用，也适合其他任何表达式，例如：`(rest+10)...`，其基本做法就是用参数包中的每个参数依次填入到表达式中参数包名所在的位置处，然后用逗号分隔。即扩展为：`(v1+10), (v2+10), (v3+10)`



## 四、转发参数包

和正常转发相同，转发参数包仍然需要做到完美转发，这要求被转发的参数的形参类型应该写作右值引用的形式，同时需要使用`std::forward`进行转发：

```cpp
class StrVec
{
public:
    template<typename... Args>
    void emplace_back(Args&&...)									 // 形参为右值引用形式
    {
        alloc.construct(first_free++, std::forward<Args>(args)...)		// 复杂形式包扩展，对每个参数应用 std::forward
    }
};
```

`std::forward<Args>(args)...`，这样的形式不仅函数参数包会进行复杂形式扩展，模板参数包也会进行相同的扩展
