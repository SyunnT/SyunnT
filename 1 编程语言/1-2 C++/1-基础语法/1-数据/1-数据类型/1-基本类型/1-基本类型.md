## 一、`void`

`void`代表无值，所以不允许任何`void`类型的对象，包括`void`数组和引用。不能对`void`类型执行`sizeof`运算符

可以用在函数的返回值类型或者参数列表中表示函数不返回值或者不传入任何实参。

也可以创建`void*`类型的指针，指向任何其他类型的指针都允许隐式转换为`void*`类型的指针，但`void*`类型的指针只能强制转换为其他类型的指针。



## 二、`std::nullptr_t`

`std::nullptr_t`是空指针常量`nullptr`的类型，定义在`cstddef`：

```c
typedef decltype(nullptr) std::nullptr_t;
```

`sizeof(std::nullptr_t) == sizeof(void*)`

`std::nullptr_t`：

1. 可以隐式转换为任何指针类型
2. 不能转换为非指针类型
3. 可以用于重载解析
4. 是字面类型（可以用作constexpr）
5. 该类型唯一的字面值就是`nullptr`



## 三、算术类型

### 1. 整数类型

#### `bool`

- 实现：`sizeof(bool)`可能不为 1，由实现定义

#### `char`

- 实现：
  - `char`：8 位，通常用于保存 ASCII 字符或多字节字符例如 UTF-8
  - `signed char`、`unsigned char`
  - `wchar_t`：在非`Windows`系统上通常是 32 位，用于保存 UTF-32 字符；在 Windows 上是 16 位，用于保存 UTF-16
  - `char16_t`：16 位，用于保存 UTF-16
  - `char32_t`：32 位，用于保存 UTF-32

#### `int`

- 类型：`int`前可以添加尺寸关键字（`short`、`long`、`long long`）以及符号性关键字（`signed`、`unsigned`）。对于不添加符号性关键字的类型则是默认`signed`的，一共可以组成 8 种类型，对于除了`int`外的其他 7 种类型，都可以省略`int`关键字
  - `short`、`unsigned short`：至少 16 位
  - `int`、`unsigned int`：至少 16 位
  - `long`、`unsigned long`：至少 32 位
  - `long long`、`unsigned long long`：至少 64 位



**尺寸实现**：`1 == sizeof(char) ≤ sizeof(short) ≤ sizeof(int) ≤ sizeof(long) ≤ sizeof(long long)`



### 2. 浮点类型

#### `float`

- 实现：单精度浮点类型，通常实现为：[IEEE-754 binary32 format](https://en.wikipedia.org/wiki/Single-precision_floating-point_format)

#### `double`

- 实现：双精度浮点类型，通常实现为：[IEEE-754 binary64 format](https://en.wikipedia.org/wiki/Double-precision_floating-point_format)

#### `long double`

- 实现：扩展精度浮点类型，可能实现为：[IEEE-754 binary128 format](https://en.wikipedia.org/wiki/Quadruple-precision_floating-point_format) 或 [x87 80-bit extended precision format](https://en.wikipedia.org/wiki/Extended_precision#x86_extended_precision_format)，在 MSVC 中和`double`实现相同。以及有可能实现为[double-double](https://en.wikipedia.org/wiki/Quadruple-precision_floating-point_format#Double-double_arithmetic)

**特殊值**：

- `INFINITY`：无限大，可以在前面添加负号表示负无穷。具体值由实现定义
- `-0.0`：和`0.0`相等，但在部分场景有用，如`1.0 / -0.0 == -INFINITY`
- `NAN`：表示非值
