## 一、`const`限定符

- 一个`const`常量必须初始化，值不一定是常量表达式。一旦该常量创建之后就无法再进行修改。
- 一个`const`常量可以用非`const`变量来初始化，同样`const`常量也可以用于初始化非`const`变量，在这样的赋值中`const`不影响过程
- 一个全局`const`对象是内部链接属性，外部无法访问，可以添加`extern`来修改为外部链接属性，但需要注意如果不提供初始化即定义，那么该`extern`声明将仅为声明。

### 1. const 引用

- `const`引用说明引用所绑定的对象是一个常量，此时作为引用对象的初始值可以是非常量的对象、字面值甚至一个一般表达式，只要其值可以转换为引用的类型即可。其行为是创建了一个引用类型的中间对象用于保存这个值，然后再让引用绑定到这个对象上。
- 不能通过`const`引用对其引用的对象进行修改



### 2. 指针和 const

- 存在指针常量和常量指针以及常量指针常量这三种情况，分别写做如下：

  ```cpp
  const type* p1;
  type* const p2;
  const type* const p3;
  ```

  - 常量指针意味着其所指的类型是一个常量，无法修改其所指的对象。
  - 指针常量则意味着指针本身是一个常量，且无法修改其指向位置
  - 常量指针常量则二者都是

- 对于指针常量来说，和其他类型的常量相同，必须初始化，在赋值拷贝时，这种常量属性不会对过程产生影响

- 对于常量指针来说，和常量引用类似，但可以不必初始化，且另一个区别是如果指向对象则必须指向相同类型的对象，或者非`const`但基本类型相同的对象

- 如果要声明一个常量指针的常量引用，应该把`&`和标识符看成一个整体，表示一个指针，它具有顶层`const`属性，这样来思考，就可以写出下面这样的声明：

  ```cpp
  const type* const &rcp = p3;
  ```



### 3. 类对象的 const

- 对一个类对象添加`const`修饰，那么其所有数据成员被添加`const`属性
- 只能调用`const`成员函数



## 二、constexpr

**常量表达式**：指不会改变且在编译过程就能得到计算结果的表达式。字面值、用常量表达式初始化的`const`对象都是常量表达式。评判一个对象是否是常量表达式根据它的数据类型和初始值共同决定，其类型必须是`const`修饰的类型，且初始值必须是一个常量表达式，只有满足以上两点一个对象才是常量表达式，否则不是。

**字面值类型**：能构成常量表达式的值的类型就是字面值类型，包括：算术类型、引用、指针以及自己定义的字面值常量类。

> 对于引用和指针来说，如果要让它们的值是一个常量表达式，则有以下限定：
>
> - 指针的初始值必须是`nullptr`或`0`，或是存储于某个固定地址中的对象（包括定义于所有函数体外的对象，函数体内的具有静态存储期的对象）
> - 引用也必须绑定到存储于某个固定地址中的对象

### 1. constexpr 变量

使用`constexpr`来修饰一个变量，那么该变量的值只能是常量表达式，如果不是常量表达式，那么程序错误。



### 2. 指针和 constexpr

和`const`不同，当用`constexpr`修饰指针时，只能用在一个位置：

```cpp
constexpr type* p = nullptr;
```

它的位置和常量指针的`const`位置相同，但实际意义是修饰指针本身是一个常量表达式，而非修饰其所指的对象。
