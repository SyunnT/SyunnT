## n、内存管理

### 1. 单个对象的分配与释放

单个对象的内存分配基本形式如下：

```cpp
Type *pvar = new Type;			// 默认初始化
Type *pvar = new Type();		// 值初始化
Type *pvar = new Type{};
Type *pvar = new Type(args);	// 调用对应的构造函数
Type *pvar = new Type{args};
Type *pvar = new Type{val_list}; // 列表初始化
```

只能使用直接初始化的形式

**动态分配`const`对象**：

```cpp
const int *pci = new const int(1024);
```

一个动态分配的`const`对象和之前一样，必须进行初始化。

**释放内存**：

```cpp
delete p;
```

- `p`必须是动态分配的内存或是一个空指针。释放一块并非`new`分配的内存，或者将相同的指针值释放多次，其行为未定义
- `delete`操作之后最好重置指针值，避免使用野指针的情况。但无法完全规避，如果有多个指针指向同一个对象的话。



### 2. 数组的分配与释放

**分配**：

```cpp
Type *arr = new Type[size];				// 默认初始化
Type *arr = new Type[size]();			// 值初始化
Type *arr = new Type[size]{};			// 值初始化
Type *arr = new Type[size]{val_list};	 // 列表初始化
```

- `size`必须是整型，但不必是常量。`size`可以是 0，且即使为 0，也会返回实际分配的内存地址。
- 列表初始化时，若初始化器的数量大于元素数量，则`new`表达式失败，不会分配任何内存。且会抛出一个类型为`bad_array_new_length`的异常，该类型定义在`<new>`中

**释放**：

```cpp
delete[] arr;
```



### 3. 定位 new

**异常处理**：

当`new`表达式失败时，会抛出一个类型为`bad_alloc`的异常。

可以如下使用`new`表达式来阻止其抛出异常：

```cpp
int * p = new (nothrow) int;
```

这种形式的`new`称为**定位`new`**
