## 一、基本概念

**线性表（List）**：零个或多个数据元素的有限序列（有序、有限），可将一个线性表记为：$(a_1, ...,a_{i-1}, a_i,a_(i+1), ..., a_n)$

**直接前驱元素**：某个元素的前一个元素即为该元素的直接前驱元素，第一个元素没有直接前驱元素

**直接后继元素**：某个元素的后一个元素即为该元素的直接后继元素，最后一个元素没有直接后继元素

**线性表的长度**：线性表元素的个数 $n(n\geqslant 0)$

**空表**：表长为 0

**位序**：一个元素的位序即它在表中的位置，例如 $a_i$ 的位序即为 $i$



## 二、ADT

> - Data：线性表的数据对象集合为 $\{a_1, a_2, ..., a_n\}$，每个元素的类型均为`DataType`。其中，除第一个元素 $a_1$ 外，每一个元素有且只有一个直接前驱元素，除了最后一个元素 $a_n$ 外，每一个元素有且只有一个直接后继元素。数据元素之间的关系是一对一的关系
> - Operation
>   - `InitList(*L)`：初始化操作，建立一个空的线性表`L`
>   - `ListEmpty(L)`：若线性表为空，返回`true`，否则返回`false`
>   - `ClearList(*L)`：将线性表清空
>   - `GetElem(L, i, *e)`：将线性表`L`中的第`i`个位置元素值返回给`e`
>   - `LocateElem(L, e)`：在线性表`L`中查找与给定值`e`相等的元素，如果查找成功，返回该元素在表中序号表示成功；否则，返回 0 表示失败
>   - `ListInsert(*L, i, e)`：在线性表`L`中的第`i`个位置插入新元素`e`
>   - `ListDelete(*L, i, *e)`：删除线性表`L`中的第`i`个位置元素，并用`e`返回其值
>   - `ListLength(L)`：返回线性表`L`中的元素个数



## 三、实现

### 1. 静态顺序数组

```c
#define MAXSIZE 20
typedef int ElemType;
typedef struct
{
    ElemType data[MAXSIZE];
    int length;
}List;
```

- 创建：不需要手动为数组分配内存
- 销毁：管理表本身的内存即可
- 插入：在插入位置之后的元素都需要后移一个位置（最好$O(1)$，最坏$O(n)$，平均$O(n)$）
- 删除：在删除位置之后的元素都需要前移一个位置（最好$O(1)$，最坏$O(n)$，平均$O(n)$）
- 修改：$O(1)$
- 按位置查找：$O(1)$
- 按值查找：根据使用的查找算法不同而不同



### 2. 动态顺序数组

```c
typedef int ElemType;
typedef struct
{
    ElemType *data;
    int length;
    int capacity;
}List;
```

- 创建：除了表本身的内存外，还需手动创建动态数组的内存

- 销毁：动态数组内存和表本身的内存

- 插入：在插入位置之后的元素都需要后移一个位置（最好$O(1)$，最坏$O(n)$，平均$O(n)$）

- 删除：在删除位置之后的元素都需要前移一个位置（最好$O(1)$，最坏$O(n)$，平均$O(n)$）

  > 插入和删除操作伴随着动态数组大小的重新分配，策略可以采用每次数组满时扩展为原来的二倍，每次数组空出一半空间时释放剩余的空间；或者只扩展不释放

- 修改：$O(1)$

- 按位置查找：$O(1)$

- 按值查找：根据使用的查找算法不同而不同



### 3. 单链表

```c
typedef int ElemType;
typedef struct node
{
    ElemType data;
    struct node* next;
}Node, List;
```

- 创建：可选带头结点或不带头结点。如果不带头结点则直接创建一个`List*`即可，如果带头结点则需要分配一个头结点的内存空间。带头结点可以简化在头部插入或删除的操作

  > 此实现中将结点指针直接作为链表表示，实际开发可以为`List`创建一个单独的结构，其中保存一个头指针，另外还可以添加一些辅助信息来提高某些操作的效率，例如表长等等。
  >
  > 如果需要提高尾部的操作效率，可以添加一个尾指针指向最后一个结点

- 销毁：销毁所有结点，然后销毁表本身

- 插入：插入操作本身只有 $O(1)$ 的时间复杂度，但是通常在插入前需要遍历来查找对应位置的结点，综合来看是 $O(n)$。

- 删除：和插入操作相同，本身只有 $O(1)$ 的时间复杂度，综合是 $O(n)$

  > 从时间复杂度方面而言，链表和数组的时间复杂度没有区别，甚至还损失了随机查找能力，但对于元素拷贝消耗较高的表来说，还是链表效率更高一些，因为链表不需要拷贝

- 修改：仍然需要先查找，综合为 $O(n)$

- 按位置查找：$O(n)$，可以使用空间换时间的方法来减小这个值

- 按值查找：根据查找算法的不同而不同



### 4. 静态链表

静态链表是用数组实现的单链表结构，其各种操作的时间复杂度和单链表相同，但静态链表相对于单链表还有一个缺点就是表的大小固定。

```c
#define MAXSIZE 100

typedef int ElemType;
typedef struct
{
    ElemType data;
    int cur;
}Component, StaticLinkList[MAXSIZE];
```

> 数组的第一个元素和最后一个元素进行特殊处理。最后一个元素作为头结点处理，其`cur`成员保存第一个元素的下标；第一个元素的`cur`成员保存备用链表第一个结点的下标。链表尾结点的`cur`成员保存`0`表示结束



### 5. 循环链表

循环链表的结构实现和单链表相同，但是在尾结点处的`next`指针需要指向首元结点

- 创建：对于循环链表，可以不需要头结点和头指针，只需要一个尾指针就可以做到快速访问头尾元素并且简化表头插入时的操作。但是在尾部插入删除的时候会有一些特殊。
- 销毁：销毁所有结点，然后销毁表本身即可
- 其余操作和单链表类似



### 6. 双向链表

```c
typedef int ElemType;
typedef struct node
{
    ElemType data;
    struct node *pre;
    struct node *next;
}Node, List;
```

> 双向链表的优点是可以反向遍历

- 创建：双向链表通常既有头指针也有尾指针，且如果添加头结点和尾结点可以简化头尾位置的插入或删除操作
- 销毁：销毁所有结点，然后销毁表本身
- 其余操作和单链表类似



### 7. 双向循环链表

双向循环链表的结构实现和双向链表相同，但第一个结点的`pre`指针指向最后一个结点，而最后一个结点的`next`指针指向第一个结点。

- 创建：循环链表通常不需要头结点和尾结点，头指针和尾指针有一个即可。
- 其余操作和单链表类似
