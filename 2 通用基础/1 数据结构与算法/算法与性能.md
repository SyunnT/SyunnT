## 一、算法

### 1. 算法的定义

算法是解决特定问题求解步骤的描述，在计算机中表现为指令的有限序列，并且每条指令表示一个或多个操作。



### 2. 算法的特性

- 输入输出：算法具有零个或多个输出，至少有一个或多个输出
- 有穷性：算法在执行有限的步骤之后，自动结束而不会出现无限循环，并且每一个步骤在可接受的时间内完成
- 确定性：算法的每一步都具有确定的含义，不会出现二义性
- 可行性：算法的每一步都必须是可行的，也就是说，每一步都能够通过执行有限次数完成



### 3. 算法设计的要求

- 正确性：算法至少应该具有输入、输出和加工处理无歧义性，能正确反映问题的需求，能够得到问题的正确答案
- 可读性：算法设计的另一目的是为了便于阅读、理解和交流
- 健壮性：当输入数据不合法时，算法也能做出相关处理，而不是产生异常或莫名其妙的结果
- 尽量低的时间复杂度和空间复杂度



## 二、性能

### 1. 时间复杂度

有两种评判算法的时间复杂度的方法，其一是 $T(n)$ 计法，一个是大 $O$ 计法。

首先，要计算一个算法的时间复杂度，首先我们要找到这个算法重复运行的部分，如果一个算法没有重复运行的部分，那么它就是常数级的时间复杂度，这样的代码通常不需要在效率层面花时间去优化了。

如果找到了一个算法重复运行的部分，那么其中重复运行的代码就可以算做一次操作，基于此，$T(n)$ 计法就是语句的总执行次数，这是一个关于输入规模的函数，使用 $T(n)$ 计法来计算算法的时间复杂度可以得到一个比较精确的值。而大 $O$ 计法就是得到 $T(n)$ 函数的数量级，例如 $T(n) = n^2 + n$ 时，这个算法的决定性数量级为 $n^2$，当 $n$ 足够大时，可以忽略 $n^2 + n$ 中的 $n$ 部分，于是我们将这个 $T(n)$ 函数记为 $O(n^2)$。

当两个解决同一个问题的不同算法采用大 $O$ 计法时不同，那么就优先选择数量级更小的算法；而如果两个算法采用大 $O$ 计法时相同，则可以去精确计算它们的 $T(n)$ 函数，选择更小的一个即可。

#### 常见时间复杂度（大 $O$ 计法）

$O(1) < O(\log n) < O(n) < O(n\log n) < O(n^2) < O(n^3) < O(2^n) < O(n!) < O(n^n)$
